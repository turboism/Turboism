# 選択ブラシ

通常のモデリングとメッシュ編集に選択ブラシを追加する Turboism 公式プラグインです。公式リリースパッケージに含まれ、Turboism の公開 SDK のみを使用します。

## 機能概要

- メッシュ編集では、現在の ArtMesh の編集可能な頂点を選択します。
- 通常モードでは、選択中の編集可能な ArtMesh の頂点とワープデフォーマの制御点を選択します。ボタンは上部ツールバーのネイティブなブラシ選択ツールの直後、区切り線の前に表示されます。
- 半径はキャンバスコンポーネントの 8–128 ピクセル、初期値は 32 です。押してドラッグし、離すと選択を適用します。
- 通常は選択を置き換え、開始時に Shift を押すと追加、Ctrl を押すと解除します。Ctrl が Shift に優先し、半径と修飾キーはストローク開始時に固定されます。
- ヒットなし、キャンセル、失敗、セッション失効時はネイティブな選択を保持します。オーバーレイは `#7B68EE`、不透明度 55% です。
- 離した後にネイティブなバウンディングボックスを更新します。選択点が二つ以上なら点の範囲、ゼロまたは一つならネイティブ規則に従いオブジェクト範囲を使用します。
- オブジェクト選択を保持し、形状や変更状態を変更しません。通常モードはネイティブな選択履歴に従い、メッシュモードは既存の Undo 履歴を保持します。

## 要件と互換性

- Turboism API：`[0.1.0,0.2.0)`。ツールサービスは Preview SDK の契約を使用します。
- 正確に審査された Cubism Editor 5.2.03、5.3.02、5.3.03 をサポートします。通常モードには、点選択とツールライフサイクルの独立した利用許可も必要です。
- 埋め込みインターフェースを使用し、他のプラグインへの依存はありません。

## インストールと有効化

Turboism 公式 Full または Thin インストーラー、あるいは Full アーカイブを使用してください。インストーラーで選択ブラシを選ぶか、プラグイン管理で有効化します。有効状態を変更した後は Editor を再起動してください。変更は次回起動時に適用されます。配布区分はストア候補です。

## 使い方

1. 通常モードで編集可能な ArtMesh またはワープデフォーマを選び、上部の選択ブラシボタンを押します。
2. 表示されている頂点や制御点の上をドラッグし、離して選択を適用します。ストローク開始時の Shift は追加、Ctrl は解除です。
3. 半径を変更するには ArtMesh のメッシュ編集に入り、ツール詳細パレットの半径スライダーを使用します。両モードは実行中のプラグインの半径を共有します。通常モード専用の半径コントロールはありません。
4. ボタンを再度押す、Escape を押す、ネイティブツールを選ぶ、またはメッシュ編集に入ると通常モードのブラシを停止します。ツール選択は排他的です。Space を押してドラッグするとネイティブなキャンバス移動ができます。
5. メッシュ編集では専用ツールバーの選択ブラシを使用します。有効中でもネイティブな確定アイコンでメッシュ編集を終了できます。

六つの状態アイコンはネイティブツールバーの中性色を使用します。初期状態は透明で外枠がなく、丸いブラシ先端で描画ツールと区別できます。

## プライバシーとデータ

ネットワーク接続やテレメトリー送信は行いません。現在の位置を読み取り、ネイティブな点選択を書き込みます。半径はメモリー内のみで保持し、プラグインファイルは書き込みません。ライフサイクルや失敗の情報が実行ログに記録される場合があります。

## 状態と制限

状態は Preview で、公式リリースパッケージに含まれます。無効化、モードや文書の失効、プラグインの破棄、ホスト終了時に所有するオーバーレイとリスナーを削除します。有効状態の変更には Editor の再起動が必要です。

通常モードとメッシュモードの基本マトリクス、ツールの排他制御、外枠とフォーカス、バウンディングボックス更新は、2026-10-02 に 5.2.03、5.3.02、5.3.03 の実機で検証しました。同じ製品ビルドの 5.2.03 手動受け入れ確認も完了しています。非初期パラメーター形状、入れ子の親、メニューやショートカットによる切り替え、複雑な文書・オブジェクト・ツールバーのライフサイクルには追加の実機証拠が必要です。高密度モデルの性能は未計測です。[検証記録](../../scripts/preview/README-mesh-edit-validation.md)を参照してください。

## トラブルシューティング

| 症状 | 確認事項 |
| --- | --- |
| ツールが表示されない | 有効化して対応 Editor を再起動し、編集可能なオブジェクトを選ぶか ArtMesh のメッシュ編集に入ってください。 |
| 選択が変わらない | 編集可能な点にストロークが当たることを確認し、セッションや投影の診断ログを確認してください。 |
| 半径変更がすぐ反映されない | 半径は開始時に固定され、新しい値は次のストロークで使われます。 |
