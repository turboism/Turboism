# 选区笔刷

Turboism 官方插件，在普通建模模式和网格编辑模式提供选区笔刷，随正式发布包交付。插件仅使用 Turboism 公开 SDK。

## 功能概述

- 网格编辑模式：刷选当前 ArtMesh 的可编辑顶点。
- 普通建模模式：刷选已选中、可编辑对象的 ArtMesh 顶点和曲面变形器控制点。入口位于顶部原生“笔刷选择工具”右侧、分隔线左侧。
- 半径范围为 8–128 个画布组件像素，默认 32。按下并拖动后，在松开时统一应用选区。
- 普通笔画替换选区，按下时按住 Shift 添加、Ctrl 移除；Ctrl 优先于 Shift。半径和修饰键在笔画开始时锁定。
- 空命中、取消、失败或失效的笔画保留原生选区。覆盖层使用 `#7B68EE`，不透明度为 55%。
- 松开后刷新原生包围框：至少两个选中点决定范围，零个或一个点遵循原生规则，使用对象范围。
- 保留对象选择，不修改模型几何或修改状态；普通模式遵循原生选区历史，网格模式保留原有撤销历史。

## 要求与兼容性

- Turboism API：`[0.1.0,0.2.0)`，工具服务使用 Preview SDK 合同。
- 支持精确审核的 Cubism Editor 5.2.03、5.3.02 和 5.3.03。普通模式另需独立准入的点选区及工具生命周期能力。
- 界面模式为嵌入式；未声明其他插件依赖。

## 安装与启用

使用 Turboism 官方 Full 或 Thin 安装器，或 Full 压缩包。在安装器中勾选选区笔刷，或通过插件管理启用。更改启用状态后重启编辑器，设置在下次启动时生效。交付状态为商店候选。

## 使用方法

1. 普通模式中选中可编辑的 ArtMesh 或曲面变形器，点击顶部选区笔刷。
2. 按下并拖动覆盖可见顶点或控制点，松开应用选区。开始笔画时按住 Shift 添加，或 Ctrl 移除。
3. 如需调整半径，进入 ArtMesh 网格编辑，在“工具详细”面板使用笔刷半径滑块。两种模式共享本次插件运行的半径，普通模式没有单独的半径控件。
4. 再次点击按钮、按 Escape、切换原生工具，或进入网格编辑，可停止普通模式笔刷。工具之间互斥；按住空格拖动可进行原生画布平移。
5. 在网格编辑模式使用对应工具栏的选区笔刷；启用时仍可点击原生确认图标退出网格编辑。

六种图标状态采用原生工具栏的中性色调；默认状态透明、无外框。圆形笔刷头用于区分原生绘制工具。

## 功能能力

| 能力 | 用户效果 |

## 隐私与数据

插件不联网，不发送遥测。它读取当前对象的位置并写入原生点选区。半径仅保存在内存中，不写入插件文件。运行日志可能记录生命周期和失败信息。

## 状态与限制

状态为 Preview，随正式发布包交付。停用、模式或文档失效、插件释放及宿主关闭时，清理所属覆盖层和监听器。插件启用状态更改需要重启编辑器。

普通模式和网格模式的基础矩阵，包括原生工具互斥、边框与焦点行为、释放后包围框刷新，已于 2026-10-02 在 5.2.03、5.3.02、5.3.03 完成实机验证；同一生产构建在 5.2.03 的人工验收通过。非默认参数形态、嵌套父级、原生菜单和快捷键切换，以及复杂文档、对象和工具栏生命周期仍需扩展实机证据；密集模型性能尚未测量。详见[验证记录](../../scripts/preview/README-mesh-edit-validation.md)。

## 故障排除

| 现象 | 检查方法 |
| --- | --- |
| 工具缺失 | 确认插件已启用并重启受支持编辑器，选中可编辑对象，或进入 ArtMesh 网格编辑模式。 |
| 选区没有变化 | 确认笔画覆盖可编辑顶点或控制点，检查日志中的会话或投影诊断。 |
| 半径没有立即改变 | 半径在笔画开始时锁定，新值用于下一笔。 |
