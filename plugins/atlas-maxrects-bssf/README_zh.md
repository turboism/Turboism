# MaxRects-BSSF 布局算法

> **Turboism 官方插件** · **状态：预览版**

为 Cubism 的纹理图集工作流程添加 MaxRects-BSSF 自动布局算法。

| 详情 | 值 |
|---|---|
| 版本 | `0.1.0` |
| 插件 ID | `dev.turboism.plugin.texture-atlas` |
| 类别 | `modeling` |
| 标签 | texture-atlas, packing, auto-layout |
| Turboism API | `[0.1.0,0.2.0)` |
| 需要 Cubism | 是 |
| 界面 | `none` |
| 许可证 | 项目许可证 |

## 功能概述

- 向纹理图集编辑器注册 MaxRects-BSSF 和原生布局选项。
- 原生自动排版入口仅处理本次传入当前纹理页的图像，支持固定/自动倍率、旋转及页内区域并行；未放入项交回原生 overflow，不搜索其他页。显式完整图集 SDK 请求保留独立规划路径。
- 持久保存所选布局模式、算法和并行搜索偏好设置。

## 要求与兼容性

- **Turboism API：**`[0.1.0,0.2.0)`。
- **Cubism：**需要 Cubism。Turboism 当前仅接受经审查的精确编辑器构件 `5.2.03`、`5.3.02` 和 `5.3.03`；本插件仅在其声明的服务和能力可用时公开相应的面向主机功能。
- **界面模式：**`none`。
- **插件依赖项：**未声明。

## 安装与启用

此官方插件是一个**商店候选项**，尚未作为已发布的商店条目提供。在市场发布前，请通过 Turboism 的官方发布包安装它，然后在**插件管理**中启用它。当不需要该工作流程时，可在同一窗口中将其禁用或卸载。

## 使用方法

1. 打开 Cubism 的纹理图集编辑器并选择自动布局工作流程。
2. 选择 MaxRects-BSSF 或原生算法，并选择是否启用并行搜索。
3. 运行自动布局；插件会在应用前验证完整方案。

| 当前页输入数 | 纹理尺寸（px） | 原生 ms | MaxRects-BSSF ms | 原生 / 新实现 |
|---:|---|---:|---:|---:|
| 100 | 4096² | 101.49 | 71.76 | **1.41×** |
| 500 | 4096² | 722.79 | 88.33 | **8.18×** |
| 1000 | 8192² | 2287.37 | 107.31 | **21.32×** |
| 2500 | 8192² | 13896.44 | 176.00 | **78.96×** |

网格模式、margin=3、自动倍率、允许旋转、parallel关闭。每次复原后的输入哈希一致，真实执行分支及几何检查通过；两侧均比例1全部放入，无重叠/越界，item与可视LayerRef变换一致。

**限制：**以上不是UI端到端耗时，也不是所有模型或legacy的性能保证。原生与新实现的margin启发式不逐像素相同；本批次未触发实际缩小或overflow。算法切换后的额外延迟及慢例已保留，不只挑选最快结果；并行也不保证更快。密集缩放、parallel、多页和保存重开仍待完整验收。

追加的 [密集页功能验证](../../validation/texture-atlas-current-page/HOST-DENSE.md)：500张图/1024²页自动倍率为新实现0.3826、原生0.3450，均全放入；固定100%禁转时新实现放入81张、原生51张，其余保持倍率并交回overflow。已观测到区域任务使用3个ForkJoin工作线程，但本样本并行没有质量收益且连续调用更慢。此小样本不更新上述加速比；overflow后一次原生Undo未恢复全部输入的现象仍待核对。

## 状态与限制

离线后续优化：少于 32 项的并行请求先尝试串行，放不全仍保留区域候选；分治准入阈值保持 16。120 个合成案例的放入数和比例不变，但部分耗时退化，不承诺普遍加速。自动缩放仍是有界启发式搜索，不保证最大可行比例。详见[离线证据](../../validation/texture-atlas-current-page/OFFLINE-POLICY.md)。已有实机表格早于本改动及 q 防御；本阶段没有新增实机运行。

- **状态：**预览版。
- 需要活动的纹理图集编辑器会话以及经审查的模型读/写服务。
- 规划或应用失败时会进行报告，且不会应用部分布局；原生算法仍可作为回退选项。

## 故障排除

| 症状 | 检查项 |
|---|---|
| 缺少自动布局选项 | 确认插件已启用，且当前主机公开了纹理图集布局能力。 |
| 布局未应用 | 检查 Turboism 日志中是否有打包或验证失败，并确认纹理图集会话处于活动状态。 |
