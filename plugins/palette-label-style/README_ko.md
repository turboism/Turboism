## 기능 개요

- 対応するパレット項目に、プリセット、クリア、カスタムカラーの操作を提供します。
- 一時的なパレット外観オーバーライドと、ネイティブなデフォーマラベル色の書き込みを調整します。
- 対応するモデルまたはプロジェクトがアクティブになったとき、プロジェクトごとの色を再適用します。

## 설치 및 활성화

この公式プラグインは、まだ公開ストアに掲載されていない**ストア候補**です。マーケットプレイスで公開されるまでの間は、Turboism の公式リリースパッケージを通じてインストールし、**Plugin Management** で有効化してください。このワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールできます。

## 사용 방법

1. 対応するデフォーマ、パーツ、またはパラメーターパレットで項目を選択し、そのコンテキストメニューを開きます。
2. テキストカラーまたは背景カラーのサブメニューを選択し、プリセット、クリア操作、またはカスタムカラーを選びます。
3. プロジェクトを再度開き、同じプロジェクトおよびオブジェクト ID に対して保存済みの色が再適用されることを確認します。

## 기능

| 宣言された機能 | ユーザーへの効果 |
|---|---|
| `ui.context-menu.contribute` | 対応するパレットコンテキストメニューに色のサブメニューを追加します。 |
| `ui.appearance.modify` | 一時的なパレットのテキスト/背景オーバーライドを適用します。 |
| `ui.dialog.contribute` | カスタムカラーフォームを開きます。 |
| `cubism.model.read` | 選択されたオブジェクトと再適用対象を解決します。 |
| `cubism.model.write` | ネイティブなデフォーマラベル色を書き込みます。 |
| `cubism.project.read` | 永続化の範囲をアクティブなプロジェクトに限定します。 |
| `file.read` | プロジェクトごとに保存された色を読み取ります。 |
| `file.write` | プロジェクトごとに保存された色を書き込み、またはクリアします。 |

## 개인정보 및 데이터

### 네트워크

ネットワーク接続を行いません。

### 로컬 데이터

プロジェクトごとの色レコードを、`palette-label-style/colors-<projectId>.properties` としてプラグインデータにアトミックに保存します。レコードには、プロジェクト/オブジェクト識別子、パレットファミリー、色の対象、`#RRGGBB` 値が含まれます。

### 원격 측정ー

このプラグインからテレメトリーが送信されることはありません。

プラグイン ID を付して、プラグインのライフサイクルおよび障害の記録が Turboism のセッションログと Cubism のホストログに表示される場合があります。

## 상태 및 제한 사항

- **ステータス:** プレビュー。
- アクティブなプロジェクト/モデルと、対応するパレットコンテキストメニューおよび外観サービスが必要です。
- 無効な保存済みレコードは無視されます。ネイティブなデフォーマ色と一時的なパレットオーバーライドは別々のホストパスを使用するため、可用性が異なる場合があります。

## 문제 해결

| 증상 | 확인 사항 |
|---|---|
| 色のサブメニューがない | 対応するパレット項目を使用し、コンテキストメニューおよび外観機能が利用可能であることを確認します。 |
| 色が復元されない | 同じプロジェクトとオブジェクト ID がアクティブであることを確認し、ストレージ/読み取り診断を確認します。 |
| カスタムカラーが拒否される | 提供されるダイアログで、有効な 6 桁の RGB カラーを入力します。 |
