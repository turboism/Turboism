## 기능 개요

- ボタンでミラー編集を有効にすると、ワープデフォーマ制御点の対称点が追従します。ネイティブのドラッグ操作の Undo グループを使用します。
- ミラー軸が有効な間、ブラシ選択ツールなどによる選択ウェイトの書き込みも同じワープデフォーマの対称制御点へリアルタイムにミラー適用します。
- キャンバス上部コントロールストリップに 3 ステート（オフ / 垂直 / 水平）のミラー軸ボタンを追加します。
- ミラー軸の有効中はホストのネイティブ描画領域ヒントに現在のモードを表示します。

## 설치 및 활성화

Turboism 公式リリースパッケージに同梱されています。インストーラーで選択するか、**プラグイン管理** から有効化・無効化できます。

## 사용 방법

1. キャンバス上部ストリップのボタンをクリックしてミラー軸を切り替えます（オフ → 垂直 → 水平）。
2. ワープデフォーマ制御点を直接ドラッグすると、対称点が追従します。モード切り替えはボタンで行い、専用ショートカットは登録しません。
3. ミラー軸が有効な状態でブラシ選択ツールを使って選択ウェイトを塗ると、同じワープデフォーマの対称制御点にも同じウェイトが適用されます。
4. ボタンを再度クリックしてオフに戻すとミラー軸が解除され、ヒント表示も消えます。

## 기능

| 宣言された機能 | ユーザーへの効果 |
|---|---|
| `cubism.deformer.read` | ワープデフォーマのグリッドを読み取り、ドラッグ前後の制御点差分を検出します。 |
| `cubism.deformer.alt-axis-mirror` | ドラッグされた制御点を有効なグリッド軸に対してミラーリングします。 |

## 권한

| 권한 | 범위 | 요청 이유 |

| `turboism.cubism.model.write` | `application` | replaceGrid を通じてミラー後の制御点位置をコミットし、ネイティブの Undo/Redo に統合します。 |

## 개인정보 및 데이터

### 네트워크

네트워크 연결을 수행하지 않습니다.

### 로컬 데이터

プラグインデータは保存しません。モデルのスナップショットを読み取り、操作中のジェスチャーに対するミラー制御点座標のみを書き込みます。

### 원격 측정ー

テレメトリーは送信しません。

プラグインのライフサイクルやエラー記録は、プラグイン ID 付きで Turboism セッションログおよび Cubism ホストログに記録される場合があります。

## 상태 및 제한 사항

- **ステータス:** プレビュー。
- v1 ではドラッグ操作全体の Undo に 2 ステップ（ミラーコミットの Undo とネイティブドラッグの Undo）が必要です。
- 有効なミラー軸上に位置する制御点はネイティブドラッグのみに追従します。
- ホスト統合が利用できない環境ではストリップボタンとヒントは表示されません。

## 문제 해결

| 증상 | 확인 사항 |
|---|---|
| ストリップボタンが表示されない | プラグインが有効であり、モデリングビューがアクティブであることを確認してください。ホストログで `BUTTON_MOUNTED` を確認できます。 |
| ドラッグしてもミラーされない | ボタンがオフ以外の状態になっているか、対象がワープデフォーマであるか、軸の反対側に対称制御点が存在するかを確認してください。 |
| ヒントが表示されない | キャンバスヒント権限が付与されているか、ホストがネイティブヒント領域を提供しているかを確認してください。 |
