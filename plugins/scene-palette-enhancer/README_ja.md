# シーンパレット拡張

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

Cubism の Scene パレットに自然順ソートと、永続化される手動の行順序を追加します。

| 項目 | 値 |
|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.scene-palette-enhancer` |
| カテゴリー | `appearance` |
| タグ | scene, palette, enhancement |
| Turboism API | `[0.1.0,0.2.0)` |
| Cubism が必要 | はい |
| インターフェース | `none` |
| ライセンス | プロジェクトライセンス |

## 機能概要

- Scene パレットのソートを昇順、降順、手動順の間で切り替えます。
- 手動での行のドラッグをサポートし、ヘッダーのソートマーカーを表示します。
- 不透明なシーンスコープごとに手動順を保存し、新しく見つかったライブ行と統合します。

## 要件と互換性

- **Turboism API:** `[0.1.0,0.2.0)`。
- **Cubism:** Cubism が必要です。Turboism は現在、正確にレビュー済みの Editor アーティファクト `5.2.03` および `5.3.02` を受け入れています。このプラグインは、宣言されたサービスと機能が利用可能な場合にのみ、各ホスト向け機能を公開します。
- **インターフェースモード:** `none`。
- **プラグイン依存関係:** 宣言されていません。

## インストールと有効化

この公式プラグインは**ストア候補**であり、まだ公開済みのストア掲載ではありません。マーケットプレイスで公開されるまで、Turboism の公式リリースパッケージからインストールし、**Plugin Management** で有効にしてください。このワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールしてください。

## 使い方

1. Cubism の Scene パレットを開き、列ヘッダーを使用してソートモードを切り替えます。
2. 手動順に切り替え、行を希望する順序へドラッグします。
3. 同じシーンスコープに戻ると、保存された手動順が復元されます。

## 機能

プラグインマニフェストには機能は宣言されていません。

## 権限

| 権限 | スコープ | 要求理由 |
|---|---|---|
| `turboism.file.read` | `application` | プロジェクトごとの Scene パレットの手動順を復元します。 |
| `turboism.file.write` | `application` | プロジェクトごとの Scene パレットの手動順を保存します。 |
| `turboism.event.subscribe` | `application` | 生成されたアノテーションのサブスクライバーを登録します。 |
| `turboism.ui.scene-table.observe` | `application` | Runtime 所有の Scene パレットスナップショット、ヘッダークリック、および並べ替えの変更を監視します。 |

## プライバシーとデータ

### ネットワーク

ネットワーク接続は行いません。

### ローカルデータ

改行区切りの項目 ID を、`manual-order-<scopeId>.txt` という名前のプラグイン状態ファイルにアトミックに保存します。スコープ ID は不透明な 64 文字の小文字16進数値でなければなりません。プロジェクトパスはこのプラグインによって保存されません。

### テレメトリー

このプラグインはテレメトリーを送信しません。

プラグイン ID が付加されたプラグインのライフサイクル記録と障害記録が、Turboism のセッションログおよび Cubism のホストログに記録されることがあります。

## 状態と制限

- **ステータス:** プレビュー。
- サポート対象の Scene テーブルサービスが必要です。ストレージを利用できない場合、ソートは継続できますが、手動順は永続化されません。
- 保存された ID は現在の行と調整されます。存在しない行は削除され、新しい行は追加されます。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| ソートコントロールがない | プラグインが有効であり、現在のホストが Scene テーブルサービスを公開していることを確認してください。 |
| 手動順が復元されない | 同じシーンスコープがアクティブであることを確認し、状態ストレージの診断情報を確認してください。 |
| 新しい行が末尾に表示される | 保存された手動順が新規作成されたシーン項目と統合される場合、これは想定された動作です。 |
