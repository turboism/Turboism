Cubism の Scene パレットに自然順ソートと、永続化される手動の行順序を追加します。

## 기능 개요

- Scene パレットのソートを昇順、降順、手動順の間で切り替えます。
- 手動での行のドラッグをサポートし、ヘッダーのソートマーカーを表示します。
- 不透明なシーンスコープごとに手動順を保存し、新しく見つかったライブ行と統合します。

## 요구 사항 및 호환성

- **SDK API 範囲:** `[0.67.0,1.0.0)`。
- **Cubism:** Cubism が必要です。Scene パレットブリッジは、正確にレビュー済みの Editor アーティファクト `5.0.00` から `5.3.04` までをすべて受け入れます。その他のアーティファクトはフェイルクローズします。Scene 専用の 23 個のプライベート UI セレクターは、すべての正確なレビュー済みアーティファクトで構造検証済み（各 jar でメンバー名・descriptor・access flag が一致）であり、バインド時にロード済みホストへ再検証も行います。

- **インターフェースモード:** `none`。

## 설치 및 활성화

この公式プラグインは**ストア候補**であり、まだ公開済みのストア掲載ではありません。マーケットプレイスで公開されるまで、Turboism の公式リリースパッケージからインストールし、**Plugin Management** で有効にしてください。このワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールしてください。

## 사용 방법

1. Cubism の Scene パレットを開き、列ヘッダーを使用してソートモードを切り替えます。
2. 手動順に切り替え、行を希望する順序へドラッグします。
3. 同じシーンスコープに戻ると、保存された手動順が復元されます。

## 개인정보 및 데이터

### 네트워크

네트워크 연결을 수행하지 않습니다.

### 로컬 데이터

バージョンヘッダー `# turboism.scene.manual-order v1` と、それに続く改行区切りの項目 ID を、`manual-order-<scopeId>.txt` という名前のプラグイン状態ファイルにアトミックに保存します。ヘッダーのない旧形式も読み取れますが、切り詰められた内容や未知の将来形式はフェイルクローズします。スコープ ID は不透明な 64 文字の小文字16進数値でなければなりません。プロジェクトパスはこのプラグインによって保存されません。

### 원격 측정ー

このプラグインはテレメトリーを送信しません。

プラグイン ID が付加されたプラグインのライフサイクル記録と障害記録が、Turboism のセッションログおよび Cubism のホストログに記録されることがあります。

## 상태 및 제한 사항

- **ステータス:** プレビュー。
- サポート対象の Scene テーブルサービスが必要です。ストレージを利用できない場合、ソートは継続できますが、手動順は永続化されません。
- 保存された ID は現在の行と調整されます。存在しない行は削除され、新しい行は追加されます。

## 문제 해결

| 증상 | 확인 사항 |
|---|---|
| ソートコントロールがない | プラグインが有効であり、現在のホストが Scene テーブルサービスを公開していることを確認してください。 |
| 手動順が復元されない | 同じシーンスコープがアクティブであることを確認し、状態ストレージの診断情報を確認してください。 |
| 新しい行が末尾に表示される | 保存された手動順が新規作成されたシーン項目と統合される場合、これは想定された動作です。 |
