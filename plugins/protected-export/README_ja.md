# Protected Export

> **Official Turboism plugin** · **Status: Preview**

## 機能概要

- タスク専用のモデルコピー上で保護付きランタイムエクスポートを実行します。作成中のドキュメントは書き換えられません。
- staged コピーに Warp と Rotation デフォルメの状態を平坦化し、ArtMesh の識別情報を難読化して、公開物に作成時の識別子が漏れないようにします。
- ソースモデルの挙動を決定論的なパラメータサンプルとして記録し、公開前に staged 成果物全体をその記録と照合して検証します。
- 検証済みの成果物をアトミックに公開し、拒否や失敗には安定した理由付きの診断を報告して、作業状態を復元します。

## 要件と互換性

- **Turboism API：**`[0.1.0,0.2.0)`。
- **Cubism：**Cubism が必要です。審査済みの正確なエディターバージョン（現時点では `5.2.03`、`5.3.03`）ごとにアドミッションが記録され、未対応または未審査のホストはプリフライトでフェイルクローズします。
- **モデル：**対象条件を満たすモデルのみが受け入れられます。未対応ファミリ、非保存キーフォーム、縮退ジオメトリ、欠落ペアを含むモデルは、部分的なエクスポートではなくブロッカー理由付きで拒否されます。
- **インターフェースモード：**`none` —— プラグインはフレームワークアクションでエクスポートを駆動し、通知とログで結果を報告します。

## インストールと有効化

この公式プラグインは**ストア候補**であり、まだストアでは公開されていません。公開までの間は、Turboism の公式リリースパッケージからインストールし、**プラグイン管理**で有効化してください。不要なときは同じ画面で無効化またはアンインストールできます。

## 使い方

1. 審査済みの正確な Cubism ホストでプラグインを有効化します。
2. モデルを開き、保護付きエクスポートアクションを実行して、パイプライン（コピーバインド、ソース挙動の記録、平坦化、難読化、検証）の完了を待ちます。
3. 公開された成果物を確認するか、パイプラインがフェイルクローズした場合は報告されたブロッカー/拒否理由を読みます。
4. 拒否されたエクスポートの診断には、プラグインログのセッションフェーズトレースを確認します。

| 権限 | スコープ | 理由 |
|---|---|---|
| `turboism.cubism.model.read` | `application` | 保護付きエクスポートのプリフライトとランタイムオーケストレーションのモデル検査のため、アクティブな Cubism モデルを読み取ります。作成中のドキュメントは書き換えません。 |

## プライバシーとデータ

プラグインはメモリ上のアクティブモデルを読み取り、エクスポート成果物は確認したタスク専用の出力先にのみ書き込みます。識別情報の難読化は公開前の staged コピーに適用されます。モデルの内容、識別対応、診断トレースがマシンの外に出ることはなく、ログはローカルの Turboism ログディレクトリに保持されます。

## 状態と制限

- **状態：**プレビュー。パイプラインは審査済みの正確な Cubism バージョンと対象条件を満たすモデルでのみアドミットされ、未アドミットの入力に対しては常にフェイルクローズします。
- 平坦化は Warp と Rotation デフォルメを対象とし、その他のファミリはアドミッション記録に応じてそのまま通過するか、エクスポートを拒否します。
- 挙動検証は決定論的なサンプル行列に限定されます。観測されていないパラメータの組み合わせは対象外です。

## トラブルシューティング

- **プリフライト拒否：**ホストまたはモデルがアドミットされていません。報告されたブロッカー理由と正確なバージョンのアドミッション記録を確認してください。
- **挙動の不一致：**staged 成果物が記録したソース挙動と乖離しています。成果物は破棄され、公開されません。
- **復元の失敗や拒否**はフェーズ付きで記録されます。失敗箇所の前後にあるプラグインログでフェーズを特定してください。
