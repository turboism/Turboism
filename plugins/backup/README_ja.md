# WebDAV 自動バックアップ同期プラグイン

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

Cubism のバックアップ成果物を、ユーザーが設定した WebDAV エンドポイントにアップロードします。

| 詳細 | 値 |
|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.backup` |
| カテゴリ | `workflow` |
| タグ | backup, webdav, automation |
| Turboism API | `[0.1.0,0.2.0)` |
| Cubism が必要 | はい |
| インターフェース | `swing` |
| ライセンス | プロジェクトライセンス |

## 機能概要

- WebDAV バックアップ設定とエンドポイントテスト用の Turboism メニュー項目を追加します。
- 保存トリガーまたはホストの自動バックアップによって生成された `.cmo3` 成果物を、制限付きの再試行でアップロードできます。
- JDK `HttpClient` を使用します。資格情報は、表示される設定および診断情報から除外されます。

## 要件と互換性

- **Turboism API:** `[0.1.0,0.2.0)`。
- **Cubism:** Cubism が必要です。Turboism は現在、レビュー済みの厳密な Editor 成果物 `5.2.03` および `5.3.02` を受け入れます。このプラグインは、宣言されたサービスと機能が利用可能な場合にのみ、各ホスト向け機能を公開します。
- **インターフェースモード:** `swing`。
- **プラグインの依存関係:** 宣言されていません。

## インストールと有効化

この公式プラグインは**ストア候補**であり、まだストアリスティングとして公開されていません。マーケットプレイス公開までは Turboism の公式リリースパッケージからインストールし、**プラグイン管理**で有効にしてください。ワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールできます。

## 使い方

1. **Turboism → WebDAV 备份设置** を開きます。
2. HTTP(S) エンドポイント、リモートパス、任意のユーザー名とパスワード、トリガーモード、タイムアウト、TLS、再試行設定を入力し、保存前にエンドポイントをテストします。
3. 同期を有効にします。設定されたトリガーが発生すると、該当するバックアップ成果物がアップロードされます。

プラグインマニフェストには機能が宣言されていません。

## プライバシーとデータ

### ネットワーク

ユーザーが設定した WebDAV HTTP(S) エンドポイントに接続し、`MKCOL`、`PROPFIND`、`PUT` を使用します。任意の Basic 認証では、設定されたユーザー名とパスワードがそのエンドポイントに送信されます。転送は、設定された保存または自動バックアップトリガーの後に自動的に実行される場合があります。TLS 検証を無効にすると転送の安全性が低下するため、信頼できるプライベートエンドポイントでのみ使用してください。

### ローカルデータ

エンドポイント設定と資格情報を `backup/webdav.cfg` のプラグイン設定に保存します。パスワード値はダイアログではマスクされ、ログおよびオブジェクトレンダリングからは編集除去されます。プラグインはアップロードするために、対象となるバックアップファイルを読み取ります。

### テレメトリー

このプラグインからテレメトリが送信されることはありません。

プラグイン ID が付与されたプラグインのライフサイクル記録および障害記録が、Turboism のセッションログと Cubism のホストログに表示される場合があります。

## 状態と制限

- **ステータス:** プレビュー。
- 到達可能な WebDAV サーバーと Cubism の保存/バックアップライフサイクルイベントが必要です。
- 無効なファイル、エンドポイントの失敗、中断されたリクエスト、および再試行の上限到達はフェイルクローズで処理されます。サーバーがアップロードを受け入れるまで、リモートバックアップの成功は仮定されません。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| エンドポイントテストに失敗する | URL、リモートパス、資格情報、TLS 設定、およびサーバーの WebDAV サポートを確認してください。 |
| バックアップがアップロードされない | 同期が有効であること、トリガーモードがイベントに一致することを確認し、プラグインスコープのログ記録を調べてください。 |
| サーバーエラーが繰り返される | HTTP ステータスと再試行設定を確認してください。プラグインが再試行するのは、上限のある一時的な失敗のみです。 |
