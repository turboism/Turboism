# 履歴パネルプラグイン

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

アクティブなドキュメントのネイティブ Undo 履歴をフローティング履歴パネルに表示し、右側の縦ツールバーボタンで切り替えます。スナップショットに束縛された Undo/Redo ナビゲーションにも対応します。

|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.historypanel` |
| カテゴリ | `workflow` |
| タグ | history, navigation, floating-window |
| Turboism API | `[0.1.0,0.2.0)` |
| Cubism が必要 | いいえ |

| ライセンス | プロジェクトライセンス |

## 機能概要

- Cubism メインウィンドウ右側の縦ツールバーにローカライズされた履歴ボタンを追加します。
- アクティブなドキュメントのネイティブ Undo 履歴を、適用済み／取り消し済みの項目として表示します。
- 通常は履歴の generation/revision を毎秒確認し、項目操作から型付き Undo/Redo API でカーソルを移動します。

## 要件と互換性

- **Turboism API:** `[0.1.0,0.2.0)`。
- **Cubism:** 初期化自体には Cubism を必要としません。履歴の表示と操作には、対応する厳密なバージョンのネイティブ履歴サービスとホスト UI 統合が必要です。
- **インターフェースモード:** `embedded`。
- **プラグインの依存関係:** 宣言されていません。

## インストールと有効化

このプラグインは Turboism Full リリースに含まれます。Full パッケージをインストールし、**プラグイン管理**で有効化または無効化してください。ネイティブ履歴操作は、現在の厳密な Cubism バージョンとアクティブなドキュメントで利用可能な機能に従います。

## 使い方

1. Turboism Full パッケージをインストールし、**プラグイン管理**で本プラグインを有効にします。
2. 右側の縦ツールバーにある履歴ボタンをクリックして、フローティングパネルを開きます。
3. ネイティブ Undo 履歴を確認します。適用済み項目のチェックを外すとその位置まで Undo し、取り消し済み項目を再チェックすると先へ Redo します。
4. 履歴ボタンをもう一度クリックしてパネルを閉じます。

## プライバシーとデータ

### ネットワーク

ネットワーク接続は行いません。

### ローカルデータ

プラグインデータは永続化しません。ネイティブ履歴スナップショットを読み取り、パネル状態、アクション登録、任意のポーリングタスクのみをメモリに保持します。

### テレメトリー

このプラグインからテレメトリは送信されません。

プラグイン ID 付きのライフサイクル、更新、ポーリング、安全な失敗の記録が Turboism セッションログおよび Cubism ホストログに表示される場合があります。

## 状態と制限

- **ステータス:** プレビューリリースプラグイン。
- ネイティブ履歴を利用できない場合、ローカライズされた利用不可状態を表示します。
- タスクスケジューラが利用できない場合はポーリングを行いませんが、初回更新のパネルは使用できます。
- パネル更新に失敗した場合はログに記録して次回ポーリングで再試行し、閉じる処理の失敗は切り替え状態から安全に除去します。
- 履歴の読み取りと移動は、レビュー済みホスト統合と宣言された権限に依存します。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| 履歴ボタンがない | 本プラグインが有効で、縦メインツールバーの提供機能が利用可能か確認してください。 |
| 履歴を利用できないと表示される | アクティブなドキュメントを開き、ネイティブ履歴サービスが利用可能か確認してください。 |
| パネルが更新されない | タスクスケジューラを確認してください。利用できない場合は初期スナップショットのみ表示します。 |
| 項目をクリックしても動かない | スナップショット、モデル書き込み権限、ネイティブ Undo/Redo 統合を確認してください。 |
| パネルを正常に閉じられない | ホストのフローティングウィンドウ破棄診断をプラグインログで確認してください。 |
