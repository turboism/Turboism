## 기능 개요

- 一般的な Cubism パレットに対して、ローカライズされたフィルターボックスの貢献を 4 件宣言します。
- ホストウィジェットを直接操作するのではなく、ランタイムがネイティブウィジェットのアタッチと行フィルタリングを担います。
- プラグインが無効化されると、すべての貢献を削除します。

## 설치 및 활성화

この公式プラグインは Turboism に同梱され、**プラグインマーケット**からも入手できます。インストール済みプラグインの有効化、無効化、アンインストールは**プラグイン管理**で行います。

## 사용 방법

1. Parameter、Deformer、Scene、または Log のパレットタブを開きます。
2. そのタブに追加されたフィルターボックスにキーワードを入力します。
3. フィールドをクリアして、フィルターなしの行セットを復元します。

## 기능

플러그인 매니페스트에 선언된 기능이 없습니다.

プラグインマニフェストには機能が宣言されていません。

## 개인정보 및 데이터

### 네트워크

네트워크 연결을 수행하지 않습니다.

### 로컬 데이터

フィルターテキストやその他のプラグインデータを永続化しません。

### 원격 측정ー

このプラグインからテレメトリが送信されることはありません。

プラグイン ID が付与されたプラグインのライフサイクル記録および障害記録が、Turboism のセッションログと Cubism のホストログに表示される場合があります。

## 상태 및 제한 사항

- **ステータス:** プレビュー。
- ランタイムのパレットフィルターレジストリと、サポートされるパレットサーフェスが必要です。
- レジストリが利用できない場合、プラグインは警告をログに記録し、フィルターボックスを一切インストールしません。

## 문제 해결

| 증상 | 확인 사항 |
|---|---|
| フィルターボックスがない | プラグインが有効であり、現在のパレットが Parameter、Deformer、Scene、または Log であることを確認してください。 |
| 行が変化しない | キーワードをクリアして再入力し、パレットフィルターのアタッチ警告がないかログを確認してください。 |
