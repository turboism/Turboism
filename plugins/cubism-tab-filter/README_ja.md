# Cubism タブフィルター

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

Cubism の Parameter、Deformer、Scene、Log パレットタブにキーワードフィルターボックスを追加します。

| 詳細 | 値 |
|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.cubism-tab-filter` |
| カテゴリ | `workflow` |
| タグ | tab-filter, workspace |
| Turboism API | `[0.1.0,0.2.0)` |
| Cubism が必要 | はい |
| インターフェース | `none` |
| ライセンス | プロジェクトライセンス |

## 機能概要

- 一般的な Cubism パレットに対して、ローカライズされたフィルターボックスの貢献を 4 件宣言します。
- ホストウィジェットを直接操作するのではなく、ランタイムがネイティブウィジェットのアタッチと行フィルタリングを担います。
- プラグインが無効化されると、すべての貢献を削除します。

## 要件と互換性

- **Turboism API:** `[0.1.0,0.2.0)`。
- **Cubism:** Cubism が必要です。Turboism は現在、レビュー済みの厳密な Editor 成果物 `5.2.03` および `5.3.02` を受け入れます。このプラグインは、宣言されたサービスと機能が利用可能な場合にのみ、各ホスト向け機能を公開します。
- **インターフェースモード:** `none`。
- **プラグインの依存関係:** 宣言されていません。

## インストールと有効化

この公式プラグインは**ストア候補**であり、まだストアリスティングとして公開されていません。マーケットプレイス公開までは Turboism の公式リリースパッケージからインストールし、**プラグイン管理**で有効にしてください。ワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールできます。

## 使い方

1. Parameter、Deformer、Scene、または Log のパレットタブを開きます。
2. そのタブに追加されたフィルターボックスにキーワードを入力します。
3. フィールドをクリアして、フィルターなしの行セットを復元します。

## プライバシーとデータ

### ネットワーク

ネットワーク接続は行いません。

### ローカルデータ

フィルターテキストやその他のプラグインデータを永続化しません。

### テレメトリー

このプラグインからテレメトリが送信されることはありません。

プラグイン ID が付与されたプラグインのライフサイクル記録および障害記録が、Turboism のセッションログと Cubism のホストログに表示される場合があります。

## 状態と制限

- **ステータス:** プレビュー。
- ランタイムのパレットフィルターレジストリと、サポートされるパレットサーフェスが必要です。
- レジストリが利用できない場合、プラグインは警告をログに記録し、フィルターボックスを一切インストールしません。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| フィルターボックスがない | プラグインが有効であり、現在のパレットが Parameter、Deformer、Scene、または Log であることを確認してください。 |
| 行が変化しない | キーワードをクリアして再入力し、パレットフィルターのアタッチ警告がないかログを確認してください。 |
