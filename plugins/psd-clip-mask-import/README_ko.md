## 기능 개요

- Turboism パネルに PSD クリッピングマスクインポート領域とインポートボタンを追加します。
- アクティブな Cubism モデルの PSD ドキュメントから順序付き関係を読み取り、関連する ArtMesh を解決します。
- 書き込み前に対象、マスク順序、PSD 参照、上書き競合、スキップ理由を表示します。
- 確認済み変更を一つの条件付きバッチとして適用し、ホストの全件適用と一回の Undo/Redo を利用します。

## 설치 및 활성화

このプラグインは Turboism Full リリースに含まれます。Full パッケージをインストールし、**プラグイン管理**で有効にしてください。現在の厳密なバージョンのホストが、レビュー済みの必要サービスをすべて提供する場合にのみ操作と書き込みを利用できます。

## 사용 방법

1. 対象モデルを開き、アクティブな PSD ドキュメントのクリッピング関係がモデル内の ArtMesh に解決できることを確認します。
2. Turboism パネルの PSD クリッピングマスクインポート領域からインポートを開始します。
3. 対象、マスク順序、ソースレイヤー、スキップ項目、上書き競合を確認します。
4. キャンセル時は書き込みません。明示的に確認した場合のみ表示された割り当てを置き換えます。
5. Cubism の Undo/Redo で確認済みバッチを取り消し、または復元します。

## 개인정보 및 데이터

### 네트워크

네트워크 연결을 수행하지 않습니다.

### 로컬 데이터

ファイルシステムまたはプラグインストレージへのアクセスを要求せず、データを永続化しません。アクティブな PSD 関係、ArtMesh ID、現在の順序付きマスクリストと反転状態のみを読み取り、明示的に確認された割り当てのみを一つの条件付きバッチで書き込みます。

### 원격 측정ー

このプラグインからテレメトリーは送信されません。

プラグイン ID 付きのライフサイクルおよび安全な失敗の記録が Turboism セッションログと Cubism ホストログに表示される場合があります。ユーザー向けエラーはホスト例外の詳細ではなく、ローカライズされた安全なメッセージを使用します。

## 상태 및 제한 사항

- **ステータス:** プレビューリリースプラグイン。
- クリッピング関係のみをインポートします。PSD 画像やテクスチャのインポート、ArtMesh 作成、レイヤーバインド修復、キャンバス拡張、一般的な PSD 再インポートは行いません。
- 置換ごとに確認が必要です。既存の非空リストまたは反転状態は上書き競合として表示され、結果は非反転になります。
- 未解決、マスク不足、自己参照、重複 ID、ドキュメント間の曖昧さ、既に一致する関係はスキップまたはフェイルクローズになります。
- コミット直前にモデルを再取得し、ドキュメント、モデル ID、計画がプレビューと一致することを検証します。変更がある場合は書き込みません。
- ホストは宣言された Cubism/UI サービスを提供する必要があり、Cubism 外では利用できません。

## 문제 해결

| 증상 | 확인 사항 |
|---|---|
| インポート領域またはボタンがない | プラグインが有効で、現在の対応 Cubism バージョンで埋め込みパネルとアクションサービスが利用可能か確認してください。 |
| プレビューがスキップ項目だけになる | PSD のベース、マスク、対象がアクティブモデル内の一意な ArtMesh に解決できるか確認してください。 |
| 確認しても変更されない | 既に一致する項目、キャンセル、曖昧さ、またはドキュメント/モデル/計画変更による安全な失敗を確認してください。 |
| インポートが安全に失敗する | ローカライズされた状態概要とプラグインログを確認し、PSD、クリッピングマスク、ダイアログ、書き込み/Undo、状態サービスが利用可能か確認してください。 |
