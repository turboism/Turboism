# Turboism コア

> **Turboism 公式プラグイン** · **ステータス: 組み込み**

Turboism の組み込みメニュー、ホームツールバー項目、設定、ログ、バージョン情報ウィンドウ、パネル、プラグインマネージャーを提供します。

| 詳細 | 値 |
|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `turboism.core` |
| カテゴリ | `system` |
| タグ | plugin-management, settings, diagnostics |
| Turboism API | `[0.1.0,0.2.0)` |
| Cubism が必要 | いいえ |
| インターフェース | `none` |
| ライセンス | プロジェクトライセンス |

## 機能概要

- 削除できない Turboism ホーム項目、および最上位の設定、プラグイン管理、ログ、バージョン情報コマンドを所有します。
- メインの Turboism 埋め込みパネルと、そのフロート/ドックのコンテキスト操作を公開します。
- 非コアプラグインのインストール、有効/無効状態、アンインストールリクエストを管理します。

## 要件と互換性

- **Turboism API:** `[0.1.0,0.2.0)`。
- **Cubism:** このプラグインは Cubism プロジェクトがなくても初期化できますが、ホスト UI の貢献は、ランタイムに利用可能な UI ホストがある場合にのみ表示されます。
- **インターフェースモード:** `none`。
- **プラグインの依存関係:** 宣言されていません。

## インストールと有効化

Turboism コアはランタイムにバンドルされています。自動的に初期化され、個別にインストール、無効化、または削除することはできません。

## 使い方

1. Turboism ホームツールバー項目または **Turboism** メニューを使用して、組み込みウィンドウを開きます。
2. **プラグイン管理**を開いて、非コアプラグインの検査、有効化、無効化、インストール、削除のスケジュールを行います。
3. **設定**または**ログ**を開いて、ランタイムを設定し診断情報を確認します。

プラグインマニフェストには機能が宣言されていません。

## プライバシーとデータ

### ネットワーク

コアプラグイン自体はネットワーク接続を行いません。

### ローカルデータ

Turboism 所有ストレージ内のランタイム設定、プラグイン管理状態、ログ、ファイル選択履歴を読み書きします。インストールされたプラグインパッケージは、ランタイムの検証済みパッケージ管理境界を通じて処理されます。

### テレメトリー

このプラグインからテレメトリが送信されることはありません。

プラグイン ID が付与されたプラグインのライフサイクル記録および障害記録が、Turboism のセッションログと Cubism のホストログに表示される場合があります。

## 状態と制限

- **ステータス:** 組み込み。
- 組み込み、バンドル済み、かつ削除不能です。コアの無効化またはアンインストールのリクエストは、ランタイムポリシーにより拒否されます。
- 一部のプラグインパッケージの変更は、次回の検出または再読み込みサイクルで有効になります。セーフモードは意図的に任意の動作を制限する場合があります。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| Turboism 項目がない | 起動診断情報を調べ、組み込みコアの初期化が完了したことを確認してください。 |
| プラグインの変更が保留中である | プラグイン管理が保留中のインストールまたはアンインストール操作を報告した場合、Turboism を再起動または再読み込みしてください。 |
| ウィンドウを開けない | セーフモード、ホスト UI の可用性、Turboism セッションログを確認してください。 |
