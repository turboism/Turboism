# メッシュ編集ミラー軸拡張

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

メッシュとデフォーマの状態を検査し、対応するメッシュ編集 UI に範囲が限定されたミラー軸角度コントロールを追加します。

| 詳細 | 値 |
|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.mesh` |
| カテゴリー | `modeling` |
| タグ | mesh, artmesh, editing |
| Turboism API | `[0.1.0,0.2.0)` |
| Cubism が必要 | はい |
| インターフェース | `embedded` |
| ライセンス | プロジェクトライセンス |

## 機能概要

- メッシュ、デフォーマ、コンテキストの数を報告する「Inspect Meshes」アクションを登録します。
- -180° から 180°、0.1° 刻み、リセット対応のミラー軸角度コントロールを提供します。
- 検査と角度変更の両方に、検証済みの型付きサービスを使用します。

## 要件と互換性

- **Turboism API:** `[0.1.0,0.2.0)`。
- **Cubism:** Cubism が必要です。Turboism は現在、レビュー済みの正確な Editor アーティファクト `5.2.03` と `5.3.02` を受け入れます。本プラグインは、宣言されたサービスと機能が利用できる場合にのみ、各ホスト向け機能を公開します。
- **インターフェースモード:** `embedded`。
- **プラグイン依存関係:** 宣言されていません。

## インストールと有効化

この公式プラグインは、まだ公開ストアに掲載されていない**ストア候補**です。マーケットプレイスで公開されるまでの間は、Turboism の公式リリースパッケージを通じてインストールし、**Plugin Management** で有効化してください。このワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールできます。

## 使い方

1. 提供されたアクション画面から **Inspect Meshes** を実行し、現在のメッシュ/デフォーマコンテキストを報告します。
2. Cubism の対応するメッシュ編集モードに入り、ミラー軸角度コントロールを見つけます。
3. 角度を調整するかリセットを使用します。このコントロールが変更するのは、保存済みプラグイン設定ではなく、現在のメッシュ編集ツールの角度です。

## 機能

| 宣言された機能 | ユーザーへの効果 |
|---|---|
| `cubism.mesh.read` | 検査用にメッシュスナップショットを読み取ります。 |
| `cubism.deformer.read` | 検査用にデフォーマスナップショットを読み取ります。 |
| `cubism.mesh.mirror-axis-angle` | 現在のミラー軸ツール角度を読み取り、書き込みます。 |
| `ui.mesh-edit.mirror-axis-angle` | 対応するメッシュ編集 UI に、範囲が限定されたコントロールを追加します。 |
| `ui.context-source.read` | 検査で使用する型付きアクションコンテキストを読み取ります。 |
| `ui.status.notify` | 検査結果とフォールバック結果を報告します。 |

## プライバシーとデータ

### ネットワーク

ネットワーク接続を行いません。

### ローカルデータ

プラグインデータを永続化しません。検査はモデル/コンテキストのスナップショットを読み取り、角度コントロールはアクティブなメッシュ編集ツールの角度のみを書き込みます。

### テレメトリー

このプラグインからテレメトリーが送信されることはありません。

プラグイン ID を付して、プラグインのライフサイクルおよび障害の記録が Turboism のセッションログと Cubism のホストログに表示される場合があります。

## 状態と制限

- **ステータス:** プレビュー。
- レビュー済みのメッシュ、デフォーマ、コンテキストソース、ミラー軸、メッシュ編集 UI サービスが必要です。
- 検査は読み取り専用です。正確なホスト統合を利用できない場合、ミラー軸コントロールは省略されます。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| ミラーコントロールがない | プラグインが有効で、メッシュ編集モードがアクティブであり、ホストがレビュー済みミラー軸 UI サービスを公開していることを確認します。 |
| 検査でオブジェクトが報告されない | メッシュまたはデフォーマを含むモデルを開き、該当するエディターコンテキストがアクティブであることを確認します。 |
| 角度変更が拒否される | 対応する -180° から 180° の範囲を確認し、プラグインログでホストサービスの可用性を確認します。 |
