Cubism のネイティブテクスチャアトラスエディターで、モデル画像の合計数と現在のテクスチャの画像数を表示します。

## 기능 개요

- ローカライズされた統計情報の1行を、アクティブなテクスチャアトラスエディター UI に追加します。
- モデル画像の合計数と選択中のテクスチャの画像数を1秒ごとに更新します。
- 読み取り失敗をホスト UI に伝播させる代わりに、利用不可状態を表示します。

## 요구 사항 및 호환성

## 설치 및 활성화

この公式プラグインは**ストア候補**であり、まだ公開済みのストア掲載ではありません。マーケットプレイスで公開されるまで、Turboism の公式リリースパッケージからインストールし、**Plugin Management** で有効にしてください。このワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールしてください。

## 사용 방법

1. モデルを開き、Cubism のテクスチャアトラスエディターを起動します。
2. ネイティブエディターウィンドウに追加された統計情報の行を見つけます。
3. 選択するテクスチャを切り替えると、現在のテクスチャの数が更新されます。合計は1秒ごとに更新されます。

## 개인정보 및 데이터

### 네트워크

네트워크 연결을 수행하지 않습니다.

### 로컬 데이터

データを永続化しません。アクティブなテクスチャアトラスセッションの概要だけを読み取り、メモリ内の UI ラベルを更新します。

### 원격 측정ー

このプラグインはテレメトリーを送信しません。

プラグイン ID が付加されたプラグインのライフサイクル記録と障害記録が、Turboism のセッションログおよび Cubism のホストログに記録されることがあります。

## 상태 및 제한 사항

- **ステータス:** プレビュー。
- レビュー済みのテクスチャアトラスセッションおよびエディター UI サービスが必要です。
- このプラグインは読み取り専用です。エディターまたはサービスが利用できない場合、この行は表示されないか、ローカライズされた利用不可状態を表示します。

## 문제 해결

| 증상 | 확인 사항 |
|---|---|
| 統計情報の行がない | ネイティブテクスチャアトラスエディターを開き、レビュー済みホストでプラグインが有効であることを確認してください。 |
| カウントがゼロのまま | モデルとテクスチャがアクティブであることを確認し、次の1秒ごとの更新を待ってください。 |
| 利用不可のテキストが表示される | テクスチャアトラスセッションの読み取り失敗について Turboism ログを確認してください。 |
