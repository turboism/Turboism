# ArtMesh Mirror

Use the dedicated canvas button to toggle ArtMesh mirror editing. Select an ArtMesh in ordinary modeling mode. Drag the diamond or axis line to freely move the axis; drag the square to rotate it. Double-click an axis control to reset to the selected meshes. This mode is independent of Warp Deformer symmetry and does not register shortcuts.
