# アートメッシュミラー

専用のキャンバスボタンでオン・オフを切り替えます。通常のモデリング画面でアートメッシュを選択し、ひし形または軸線をドラッグして軸を移動、四角をドラッグして回転します。軸コントロールのダブルクリックでリセットできます。ワープデフォーマの対称編集とは独立しており、ショートカットは登録しません。
