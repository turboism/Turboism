# 매개변수 잠금 플러그인

> **Turboism 공식 플러그인** · **상태: 프리뷰**

Cubism 매개변수 값의 의도치 않은 수정을 방지하고, 세션 간 지속성 및 파라미터 행/그룹 단위의 네이티브 잠금 아이콘 통합을 제공합니다.

| 세부 정보 | 값 |
|---|---|
| 버전 | `0.1.0` |
| 플러그인 ID | `dev.turboism.plugin.parameter-lock` |
| 카테고리 | `workflow` |
| 태그 | parameter, lock, palette, safety |
| Cubism 필요 여부 | 예 |
| 인터페이스 | `embedded` |
| 라이선스 | 프로젝트 라이선스 |

## 기능 개요

- 호스트에 의해 매개변수 값이 변경되기 전에 쓰기 요청을 가로채어, 잠긴 매개변수의 현재 값을 반환합니다.
- 매개변수 팔레트의 각 매개변수 행 및 매개변수 그룹 행에 네이티브 전치 잠금 아이콘을 직접 통합합니다(Parts/Deformer 팔레트의 행 단위 잠금 동작에 준함).
- 매개변수 행의 잠금 아이콘을 클릭하면 에디터의 선택 상태를 변경하지 않고 해당 매개변수 단일 잠금 상태를 전환합니다.
- 매개변수 폴더 행의 잠금 아이콘을 클릭하면 중첩된 하위 그룹을 포함한 모든 하위 매개변수를 재귀적으로 잠그거나 해제합니다(순환 방지 메커니즘 포함).
- 단일 매개변수의 잠금 상태가 변경되면 상위 및 조상 그룹의 아이콘 상태(미잠금, 혼합, 전체 잠금)에 즉시 반영됩니다.
- 행 단위 독립 잠금 방식으로 전환됨에 따라 메인 툴바 토글 버튼은 제거되었습니다.
- 쓰기 훅을 통해 기존 값을 반환하며, 플러그인이 에디터 히스토리 스택을 직접 수정하지 않습니다.
- 모델 고유의 직렬화된 GUID(`CModelSource.guid`)를 키로 사용하여 세션 간에 잠금 상태를 영구 보존하고 재시작 시 자동으로 복원합니다.
- 플러그인을 비활성화하거나 제거할 때 메모리 상의 인터셉트 동작과 행 아이콘 등록을 즉시 해제하면서도, 디스크의 설정 파일은 안전하게 보존하여 재활성화 시 복원할 수 있도록 합니다.

## 설치 및 활성화

이 프리뷰 플러그인은 **Plugin Market**을 통해 배포되며, Turboism 표준 설치 프로그램에는 번들로 포함되지 않습니다. 플러그인 마켓에서 직접 설치하거나 `./gradlew :plugins:parameter-lock:jar`로 빌드하여 **플러그인 관리**에서 활성화하십시오.

## 사용 방법

1. **매개변수** 팔레트에서 임의의 매개변수 행 전치 잠금 아이콘을 클릭하여 잠금/해제 상태를 전환합니다.
2. 임의의 폴더 행 전치 잠금 아이콘을 클릭하여 폴더 내의 모든 매개변수를 재귀적으로 잠금/해제합니다.
3. 잠긴 매개변수의 슬라이더를 조작하거나 텍스트를 입력해도 값이 변경되지 않습니다.
4. 모델을 저장하고 다시 열면 잠금 상태와 아이콘 표시가 유지되는 것을 확인할 수 있습니다.

## 기능

| 선언된 기능 | 사용자 효과 |
|---|---|
| `ui.appearance.modify` | 매개변수 및 매개변수 그룹 팔레트 엔트리 전치 액션을 재정의하여 네이티브 잠금 아이콘을 제공합니다. |
| `cubism.model.read` | 활성 모델 매개변수 및 네이티브 모델 GUID를 읽습니다. |
| `cubism.model.observe` | 모델 라이프사이클 이벤트를 수신하여 지속적인 잠금 상태를 관리합니다. |
| `cubism.model.intercept` | 매개변수 쓰기 요청을 가로채어 잠긴 매개변수의 수정을 방지합니다. |
| `file.read` | 플러그인 저장소에서 지속된 매개변수 잠금 상태를 읽습니다. |
| `file.write` | 플러그인 저장소에 매개변수 잠금 상태를 기록합니다. |

## 개인정보 및 데이터

### 네트워크

네트워크 연결을 수행하지 않습니다.

### 로컬 데이터

잠금 목록을 `locks/<sha256(guid)>.json`으로 샌드박스 플러그인 저장소에 유지합니다. 모델 GUID 및 매개변수 ID 문자열만 포함합니다.

### 원격 측정

이 플러그인은 원격 측정을 전송하지 않습니다.

플러그인 라이프사이클 및 오류 기록은 플러그인 ID가 첨부되어 Turboism 세션 로그 및 Cubism 호스트 로그에 나타날 수 있습니다.

## 상태 및 제한 사항

- **상태:** 프리뷰.
- 훅 변경 차단, 행 단위 전치 액션, 재귀 그룹 계층 처리, 지속성 및 모델 간 격리를 검증했습니다.
- 쓰기 억제 메커니즘은 호스트 쓰기 전에 매개변수의 현재 값을 반환합니다.
- 네이티브 모델 GUID에 액세스할 수 있는 활성 모델 문서가 필요합니다.

## 문제 해결

| 증상 | 확인 사항 |
|---|---|
| 매개변수 값이 변경됨 | 플러그인 관리에서 활성화되어 있고 대상 매개변수가 잠금 목록에 포함되어 있는지 확인합니다. |
| 매개변수 행 아이콘이 표시되지 않음 | 모델 로드가 완료되었고 외관 변경 권한이 허용되어 있는지 확인합니다. |
| 다시 연 후 잠금이 복원되지 않음 | 모델이 저장되었고 `.cmo3` 파일의 네이티브 GUID가 수동으로 변경되지 않았는지 확인합니다. |
