# パラメータロックプラグイン

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

Cubism パラメータ値の誤編集を防ぎ、セッション間での永続化および行単位・パラメータグループ単位でのネイティブロックアイコン統合を提供します。

|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.parameter-lock` |
| カテゴリ | `workflow` |

| Cubism が必要 | はい |
| インターフェース | `embedded` |
| ライセンス | プロジェクトライセンス |

## 機能概要

- ホストによるパラメータ値の変更前に書き込み要求をインターセプトし、ロックされたパラメータの現在値を返します。ネイティブスライダーのドラッグとテキスト入力の検証範囲は、実機検証記録で個別に管理します。
- パラメータパレットの各パラメータ行およびパラメータグループ行に、ネイティブの前置ロックアイコンを直接統合します（Parts/Deformer パレットの行単位ロック動作に準拠）。
- パラメータ行のロックアイコンをクリックすると、エディタの選択状態を変更することなく、そのパラメータ単体のロック状態を切り替えます。
- パラメータフォルダ行のロックアイコンをクリックすると、ネストされたサブグループを含む配下の全パラメータを再帰的にロックまたは解除します（循環防止機構付き）。一部ロック（混合状態）では全ロック、全ロック状態では全解除、全未ロック状態では全ロックを実行し、空のグループは誤ロックされず未ロック状態を保持します。
- 単一パラメータのロック状態が変更されると、親や祖先グループのアイコン状態（未ロック、混合、全ロック）に即座に反映されます。
- メインツールバーの切り替えボタンは、行単位の独立ロックに移行したため削除されました。
- 書き込みフックから現在値を返し、プラグインは履歴スタックを直接変更しません。Undo/Redo の動作は実機での確認が必要です。
- モデル固有のシリアライズされた GUID（`CModelSource.guid`）をキーとしてセッション間でロック状態を永続化し、再起動時に自動復元します。
- プラグインを無効化またはアンインストールした際はメモリ上のインターセプト動作と行アイコン登録を直ちに解除しつつ、ディスク上の設定ファイルを保持して再有効化時に復元できるようにします。

## 要件と互換性

- **SDK API 範囲:** `[0.67.0,1.0.0)`。
- **Cubism:** Cubism が必要です。Turboism は現在、審査済みの Editor アーティファクト `5.0.00` から `5.3.04`（`5.3.03` を含む）を厳密に認可しています。
- **インターフェースモード:** `embedded`。
- **プラグイン依存関係:** 未宣言。

- 未ロック時はパーツ／デフォーマタブと同じネイティブの円形プレースホルダーを常時表示し、ロック時は錠前、混在グループは無効色の錠前を表示します。

- 錠前はリンクアイコン横の独立領域に配置し、名前のネイティブな配置を維持して長い名前との重なりを防ぎます。ロック中の名前はテーマの無効テキスト色になり、解除すると元の色に戻ります。
- ロックしたパラメータのドラッグ・数値編集領域はグレー表示で操作不可となり、錠前は解除に使えます。2軸結合行では片軸のロックで共有ドラッグを無効化しますが、未ロック軸の数値入力は維持します。

**実機検証：** Cubism 5.2.03 と 5.3.02 で、パラメータ行のクリックと SDK・ネイティブコントローラーの書き込み抑制を確認しました。両バージョンでは実際の単層グループで MIXED → 全ロック → 全解除を全子パラメータに対して検証しました。隔離モデル内で一時的に追加したメンバーは元のグループへ戻し、モデルは保存していません。5.3.02 の別プロセス間の行ロック復元も検証済みです。深い入れ子はオフライン検証済みですが、実機の多層グループ、物理ドラッグ、キー入力、Undo/Redo、複数モデル切り替えは未検証です。

## インストールと有効化

このプレビュープラグインは **Plugin Market** を通じて配布され、Turboism の標準インストーラーにはバンドルされていません。プラグインマーケットから直接インストールするか、`./gradlew :plugins:parameter-lock:jar` で JAR をビルドし、**プラグイン管理**で有効化してください。

## 使い方

1. **パラメータ**パレットで、任意のパラメータ行の前置ロックアイコンをクリックしてロック/解除を切り替えます。
2. 任意のフォルダ行の前置ロックアイコンをクリックして、フォルダ内の全パラメータを再帰的にロック/解除します。
3. ロックされたパラメータのスライダーを操作しても値は変わりません。
5. モデルを保存して開き直すと、ロック状態とアイコン表示が保持されていることを確認できます。

| `file.write` | プラグインストレージにパラメータロック状態を書き込みます。 |

## プライバシーとデータ

### ネットワーク

ネットワーク接続は行いません。

### ローカルデータ

プラグインのサンドボックスストレージ（`StorageRoot.STATE`）に `locks/<sha256(guid)>.json` としてアトミックに保存します。モデルの GUID とパラメータ ID 文字列のみが含まれます。

### テレメトリー

このプラグインからテレメトリーが送信されることはありません。

## 状態と制限

- **ステータス:** プレビュー。
- オフラインの単体テストおよび結合テストにおいて、フックによる値変更の抑制、行前置アクション登録、深層グループの再帰・循環防止、永続化、およびモデル間分離を検証済みです。行 UI の実機検証結果と制限は上記の記録に記載しています。
- 新しい行単位 UI は旧ツールバーの実機検証結果と等価ではありません。
- 値変更の抑制はホスト書き込み前に現在値を返す方式を採用しています。ネイティブ履歴との詳細な相互作用はインストールされた Cubism の書き込みパイプラインに依存します。
- アクティブなモデリングドキュメントとネイティブモデル GUID へのアクセスが必要です。
- ロック設定は `.cmo3` ファイル内にシリアライズされた `CModelSource.guid` に紐付けられます。Live2D Cubism Editor の仕様上、「名前を付けて保存」（Save As）や直接のファイルコピーで複製されたモデルは元の GUID を保持するため、複製ファイル間でも同じロック設定が共有されます。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| パラメータ値が変更されてしまう | プラグイン管理で有効化されており、対象パラメータがロック一覧に含まれていることを確認します。 |
| パラメータ行のアイコンが表示されない | モデルが読み込み完了しており、外観変更権限が許可されていることを確認します。 |
| 再起動後にロックが復元されない | モデルが保存されており、`.cmo3` ファイルのネイティブ GUID が改変されていないことを確認します。 |
