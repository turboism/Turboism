> **Turboism 公式プラグイン** · **ステータス： プレビュー**

Cubism のテクスチャアトラスワークフローに、Cubism 5.4 の輪郭パッキング
スタイルの不規則ポリゴン自動レイアウトアルゴリズムを追加します。カーネルは
MIT ライセンスの `whitegreen/Dalsoo-Bin-Packing`（コミット `bde2a3e`）の
独立移植です（`LICENSE`/`NOTICE` 参照）。本プラグインは Cubism 5.4 を
同梱・呼出・互換性の主張を**しません**。現在サポートされているホスト
（`5.2.00`〜`5.3.04`）で動作します。

## 기능 개요

- アトラス全体のワンクリック配置に対応し、元の画像サイズを維持して回転せずに配置します。対応ホストでは元のメッシュ輪郭を使い、取得できない場合は画像矩形にフォールバックします。フォルダー配置ではフォルダー間でページを統合し、既存ページの空きを優先します。
- 既存の MaxRects-BSSF 矩形バックエンドに加えて `dalsoo` テクスチャ
  アトラスレイアウトアルゴリズムを登録します。矩形バックエンドは変更
  されません。
- 実際の凹型輪郭（material-local の `drawDataShapes`、検証済みセレクタ経由）
  でパックします。バウンディングボックスも凸包も使いません。
- 回転モード `NONE`、`QUARTER`（90° 単位）、`FREE`（18 候補角度）、固定/
  自動共通スケール、ページマージン、項目ごとのポリシー（参加、角度保持、
  倍率保持、位置保持——固定項目は可動項目の前に障害物として配置）を
  サポートします。
- 検証済みポリゴンプランでネイティブ自動レイアウトコールバックを処理
  します。他のアルゴリズムは従来の矩形パスを継続します。
- プランは適用前に最新のホスト状態で検証（同一性、重なり、マージン、
  ロック）され、矩形サービスと同じ段階的 affine/undo 境界で書き戻され
  ます。失敗時は完全にロールバックします。

## 正直な制限

- **輪郭フォールバック。** ホスト項目に利用可能な輪郭がない場合、
  バウンディング矩形にフォールバックし、診断で `outlineSource=
  BOUNDS_FALLBACK` と報告します。輪郭パッキングとは称しません。
- **穴。** 輪郭内の穴はパック前に保守的に埋められ、診断（`holesFilled`）
  で報告されます。複雑な自己交差トポロジーは矩形へ退化する場合があり
  ます。
- **矩形パスの縮退。** 従来の矩形レイアウト契約は任意角度を表現できない
  ため、そのパス経由では `FREE` は `QUARTER` に縮退します。45° の配置を
  偽の 90° 回転に丸めることはありません。
- **パフォーマンス。** 凹型パッキングは矩形より桁違いに高コストです。
  100 個の凹型項目は回転モードと品質プリセットにより数秒〜数分、
  500 個では数分かかります。`AUTO` バックエンドは準矩形のみの入力を
  矩形パスへ振り分けます。測定値は
  [オフラインエビデンス](../../validation/texture-atlas-current-page/OFFLINE-POLYGON.md)
  と生 CSV を参照。合成オフラインデータであり、ホスト計測ではありません。
- **ネイティブ 5.4 の主張なし。** Cubism 5.4 alpha2 JAR は読み取り専用
  研究にのみ使用され、そのアーティファクトは許可されていません。ネイ
  ティブとの比較数値も主張しません。

## 사용 방법

1. Cubism のテクスチャアトラスエディタで自動レイアウトワークフローを
   開きます。
2. `dalsoo` アルゴリズムを選択します。選択中は下記のパッキングコントロー
   ルがダイアログに表示されます。他のアルゴリズム選択時は無効化され、
   値は無視されます。
3. 自動レイアウトを実行します。プラグインは完全なプランを適用前に
   検証し、診断（バックエンド、輪郭、フォールバック、穴、スケール、
   オーバーフロー）を報告します。

## ダイアログオプションと永続化設定

`dalsoo` 選択時、自動レイアウトダイアログに次のコントロールが追加されま
す。すべての値は永続化ポリシー（`texture-atlas-dalsoo/layout.cfg`）へ
ブリッジされ、次回実行時に有効になります。

| ダイアログコントロール | 設定キー | Cubism 5.4 対応 | 備考 |
|---|---|---|---|
| 回転：`NONE` / `QUARTER` / `FREE` | `rotation` | 回転粒度コンボ | `FREE` は 18 候補角度（20° 刻み）で計画し、完全なアフィンパスで書き戻します。矩形フォールバックは `FREE` を `QUARTER` へ正直に縮退します。 |
| ロックプリセット：`NONE` / `ALL` / `ANGLE` / `SCALE` / `ANGLE_SCALE` / `POS_ANGLE` | `lock-preset` | `AutoLayoutLock`（`fixPosition`/`fixRotate`/`fixScale`） | グローバル既定レイヤー。明示的な項目別ポリシー（`item-policies`）が優先します。 |
| スケールモード：自動 / 固定 | `auto-scale`、`fixed-scale-percent` | 自動/固定スケール入力 | 固定スケールはパーセント（1-800）。自動スケールは 1 を超えません（`s = min(1, ·)`）。 |
| スケール許容誤差 | `auto-scale-tolerance-permille` | `AUTO_SCALE_TOLERANCE` | スケール探索の相対ステップ下限。既定 `0.005`（パーミルで保存）。 |
| スケール最大試行 | `auto-scale-max-try` | `AUTO_SCALE_MAX_TRY` | 試行上限。`0` は品質プリセットから導出（`FAST` 8、`BALANCED` 12、`DENSE` 20）。 |
| カーネル：Abey / Dalalah | `use-abey` | - | プランナーが使う Dalsoo カーネルバリアント。 |
| 並列検索 | `parallel` | - | 決定的並列バリアント。アルゴリズムの `supportsParallel` 宣言でゲート。 |

Cubism 5.4 のテクスチャ圧縮プリセット（`PRESET_COMPRESSION`、
`IMAGE_QUALITY`、`CUSTOM`）はパッキングと直交するため、意図的に実装して
いません。

既定値は変更前の動作を維持します：回転 `QUARTER`、ロックプリセット
`NONE`、自動スケール（許容誤差 `0.005`）、品質プリセット由来の試行上限、
Abey カーネル、逐次計画。

## Geometry500：ネイティブ・Dalsoo・BSSF の比較（2026-10-19）

Cubism 5.3.03、DW-Proton / `:0` 環境で、同じ500画像のGeometryサンプルと、
同一のフレームワーク・プラグイン・プローブ成果物を使用しました。
各アルゴリズムを新規ホストで1回ずつ直列実行しました。
ページ8192×8192、マージン3、メッシュモード、自動倍率、回転許可。
Dalsooの回転設定は `QUARTER` です。

| アルゴリズム | 配置メソッド時間（秒） | OK操作 → 進捗ウィンドウ終了（秒） |
| --- | ---: | ---: |
| ネイティブ | 192.94 | 193.16 |
| Dalsoo | 12.20 | 12.51 |
| MaxRects-BSSF | **0.20** | **0.45** |

メソッド時間では、Dalsooはネイティブの約 **15.8倍**、BSSFはDalsooの約
**60.5倍**高速でした（UI時間では27.6倍）。3方式とも倍率100%で全500画像を
配置し、重なり・ページ外配置・溢れはなく、LayerRef変換も一致しました。
ホスト識別、サンプル不変、正常終了、安全な後処理の検証もすべて合格しました。

各1回のプローブ付き計測であり、中央値や一般的な性能保証ではありません。
UI時間にはネイティブ / Dalsoo / BSSFそれぞれ12.28 / 18.30 / 28.25 msの
入力プローブ負荷を含み、モデル読み込みとウィンドウ終了後の出力検証は含みません。
Dalsooは500個のホスト輪郭を取得し、矩形へのフォールバックはありません
（500リング、2000頂点）。複雑な凹形状や `FREE` 回転の性能、最適な配置密度を
示すものではありません。
[計測レポート・ジョブ記録](../../validation/texture-atlas-current-page/HOST-GEOMETRY500-THREE-WAY.md)と
[生データ](../../validation/texture-atlas-current-page/host-geometry500-three-way-samples.csv)を参照してください。

## 상태 및 제한 사항

- **ステータス:** プレビュー。
- アクティブなテクスチャアトラスエディタセッションとレビュー済みの
  モデル読み書きサービスが必要です。
- プランニングまたは適用の失敗は部分的なレイアウトを適用せず報告され
  ます。MaxRects-BSSF とネイティブアルゴリズムは引き続きフォールバック
  として利用可能です。
- Cubism 5.2.03、5.3.02、5.3.03 の実ホスト記録があります。54 回の
  レイアウト行列には Dalsoo の 18 回を含み、全項目の配置、有限のページ内
  出力、プラグインによる処理を確認しています。最適化後は 5.3.03 で
  3 ケースを再測定しました。[実ホスト性能記録](../../validation/texture-atlas-current-page/HOST-PERF-MATRIX.md)を参照してください。
  全対応ホストの全オプション、Undo/Redo、保存・再読込の検証を意味しません。

## 문제 해결

| 증상 | 확인 사항 |
|---|---|
| `dalsoo` 選択肢がない | プラグインが有効で、ホストがテクスチャアトラスレイアウトケーパビリティを公開しているか確認。 |
| 項目が矩形でパックされる | ホスト輪郭ソースが利用不可の可能性。診断の `BOUNDS_FALLBACK` を確認。 |
| レイアウトが遅い | 凹型パッキングは高コスト。品質プリセットを下げるか、`QUARTER`/`NONE` を使うか、準矩形入力では `AUTO`/矩形バックエンドを選択。 |
| レイアウトが適用されない | Turboism ログで検証失敗を確認。プランは原子的に拒否されます。 |
