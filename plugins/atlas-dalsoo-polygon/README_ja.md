# Dalsoo ポリゴンパッキングアルゴリズム

> **Turboism 公式プラグイン** · **ステータス： 開発中**

Cubism のテクスチャアトラスワークフローに、Cubism 5.4 の輪郭パッキング
スタイルの不規則ポリゴン自動レイアウトアルゴリズムを追加します。カーネルは
MIT ライセンスの `whitegreen/Dalsoo-Bin-Packing`（コミット `bde2a3e`）の
独立移植です（`LICENSE`/`NOTICE` 参照）。本プラグインは Cubism 5.4 を
同梱・呼出・互換性の主張を**しません**。現在サポートされているホスト
（`5.2.03`、`5.3.02`、`5.3.03`）で動作します。

## 機能

- 既存の MaxRects-BSSF 矩形バックエンドに加えて `dalsoo` テクスチャ
  アトラスレイアウトアルゴリズムを登録します。矩形バックエンドは変更
  されません。
- 実際の凹型輪郭（material-local の `drawDataShapes`、検証済みセレクタ経由）
  でパックします。バウンディングボックスも凸包も使いません。
- 回転モード `NONE`、`QUARTER`（90° 単位）、`FREE`（18 候補角度）、固定/
  自動共通スケール、ページマージン、項目ごとのポリシー（参加、角度保持、
  倍率保持、位置保持——固定項目は可動項目の前に障害物として配置）を
  サポートします。
- 検証済みポリゴンプランでネイティブ自動レイアウトコールバックを処理
  します。他のアルゴリズムは従来の矩形パスを継続します。
- プランは適用前に最新のホスト状態で検証（同一性、重なり、マージン、
  ロック）され、矩形サービスと同じ段階的 affine/undo 境界で書き戻され
  ます。失敗時は完全にロールバックします。

## 要件と互換性

- **Turboism API:** `[0.1.0,0.2.0)`。
- **Cubism:** 正確にレビュー済みの Editor アーティファクト `5.2.03`、
  `5.3.02`、`5.3.03` のみ。Cubism 5.4 は未許可です。SDK 契約には将来の
  公式 5.4 ホストネイティブ provider 用に `HOST_NATIVE` バックエンド
  スロットが予約されています。
- **インターフェースモード:** `none`。
- **プラグイン依存:** なし。

## 正直な制限

- **輪郭フォールバック。** ホスト項目に利用可能な輪郭がない場合、
  バウンディング矩形にフォールバックし、診断で `outlineSource=
  BOUNDS_FALLBACK` と報告します。輪郭パッキングとは称しません。
- **穴。** 輪郭内の穴はパック前に保守的に埋められ、診断（`holesFilled`）
  で報告されます。複雑な自己交差トポロジーは矩形へ退化する場合があり
  ます。
- **矩形パスの縮退。** 従来の矩形レイアウト契約は任意角度を表現できない
  ため、そのパス経由では `FREE` は `QUARTER` に縮退します。45° の配置を
  偽の 90° 回転に丸めることはありません。
- **パフォーマンス。** 凹型パッキングは矩形より桁違いに高コストです。
  100 個の凹型項目は回転モードと品質プリセットにより数秒〜数分、
  500 個では数分かかります。`AUTO` バックエンドは準矩形のみの入力を
  矩形パスへ振り分けます。測定値は
  [オフラインエビデンス](../../validation/texture-atlas-current-page/OFFLINE-POLYGON.md)
  と生 CSV を参照。合成オフラインデータであり、ホスト計測ではありません。
- **ネイティブ 5.4 の主張なし。** Cubism 5.4 alpha2 JAR は読み取り専用
  研究にのみ使用され、そのアーティファクトは許可されていません。ネイ
  ティブとの比較数値も主張しません。

## インストールと有効化

この公式プラグインは**ストア候補**であり、まだ公開リストではありません。
Turboism 公式リリースパッケージでインストール後、**プラグイン管理**で
有効化してください。

## 使い方

1. Cubism のテクスチャアトラスエディタで自動レイアウトワークフローを
   開きます。
2. `dalsoo` アルゴリズムを選択し、必要に応じて並列バリアント検索を
   有効にします。
3. 自動レイアウトを実行します。プラグインは完全なプランを適用前に
   検証し、診断（バックエンド、輪郭、フォールバック、穴、スケール、
   オーバーフロー）を報告します。

## プライバシーとデータ

### ネットワーク

ネットワーク接続を行いません。

### ローカルデータ

レイアウト設定と項目ポリシーをプラグイン設定に保存します。ワークフロー
実行時のみアクティブなテクスチャアトラス状態を読み書きします。

### テレメトリ

本プラグインはテレメトリを送信しません。

## ステータスと制限

- **ステータス:** 開発中。
- アクティブなテクスチャアトラスエディタセッションとレビュー済みの
  モデル読み書きサービスが必要です。
- プランニングまたは適用の失敗は部分的なレイアウトを適用せず報告され
  ます。MaxRects-BSSF とネイティブアルゴリズムは引き続きフォールバック
  として利用可能です。
- 3 つの対応バージョンでの実ホスト受け入れは未実施です。現時点では
  オフラインベンチマークと単体/統合テストのみが実行されています。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| `dalsoo` 選択肢がない | プラグインが有効で、ホストがテクスチャアトラスレイアウトケーパビリティを公開しているか確認。 |
| 項目が矩形でパックされる | ホスト輪郭ソースが利用不可の可能性。診断の `BOUNDS_FALLBACK` を確認。 |
| レイアウトが遅い | 凹型パッキングは高コスト。品質プリセットを下げるか、`QUARTER`/`NONE` を使うか、準矩形入力では `AUTO`/矩形バックエンドを選択。 |
| レイアウトが適用されない | Turboism ログで検証失敗を確認。プランは原子的に拒否されます。 |
