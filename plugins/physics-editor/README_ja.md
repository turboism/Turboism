# 物理エディター

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

Cubism の Physics Settings グループリストに、すべて選択の操作と再表示時の状態保持を追加します。

| 項目 | 値 |
|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.physics-editor` |
| カテゴリー | `modeling` |
| タグ | physics, editing, simulation |
| Turboism API | `[0.1.0,0.2.0)` |
| Cubism が必要 | はい |
| インターフェース | `swing` |
| ライセンス | プロジェクトライセンス |

## 機能概要

- グループのすべて選択を有効にした、レビュー済みの Physics Settings ポリシーを提供します。
- Physics Settings ウィンドウを再度開いたときに、グループ選択状態を保持するよう要求します。
- 無効化時には、この拡張を適切に終了します。

## 要件と互換性

- **Turboism API:** `[0.1.0,0.2.0)`。
- **Cubism:** Cubism が必要です。Turboism は現在、正確にレビュー済みの Editor アーティファクト `5.2.03`、`5.3.02`、および `5.3.03` を受け入れています。このプラグインは、宣言されたサービスと機能が利用可能な場合にのみ、各ホスト向け機能を公開します。
- **インターフェースモード:** `swing`。
- **プラグイン依存関係:** 宣言されていません。

## インストールと有効化

この公式プラグインは**ストア候補**であり、まだ公開済みのストア掲載ではありません。マーケットプレイスで公開されるまで、Turboism の公式リリースパッケージからインストールし、**Plugin Management** で有効にしてください。このワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールしてください。

## 使い方

1. プラグインを有効にしてから、Cubism の Physics Settings エディターを開きます。
2. グループリストのヘッダーにあるすべて選択の操作で、すべてのグループを有効または無効にします。
3. エディターを閉じて再度開きます。提供された保持ポリシーにより、サポート対象の選択状態が維持されます。

## プライバシーとデータ

### ネットワーク

ネットワーク接続は行いません。

### ローカルデータ

プラグイン所有のファイルは書き込みません。状態の保持は、レビュー済みの Physics Editor ホストサービスに委ねられます。

### テレメトリー

このプラグインはテレメトリーを送信しません。

プラグイン ID が付加されたプラグインのライフサイクル記録と障害記録が、Turboism のセッションログおよび Cubism のホストログに記録されることがあります。

## 状態と制限

- **ステータス:** プレビュー。
- アクティブな Cubism ホストでサポートされる Physics Editor 拡張サービスが必要です。
- このプラグインは意図的にすべて選択と再表示時の状態保持に限定されており、Cubism の物理エディターを置き換えるものではありません。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| すべて選択がない | Physics Settings を開く前にプラグインが有効になっていることを確認し、ホストサービスの可用性を確認してください。 |
| 選択状態が保持されない | 拡張の接続失敗についてプラグインログを確認し、プラグインがアクティブになってからエディターを再度開いてください。 |
