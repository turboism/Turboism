# 物理演算設定拡張

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

Cubism の「物理演算・シーンブレンド設定」ダイアログのグループリストに表頭すべて選択/解除の操作を追加し、同一セッション内で再表示した際の状態保持を提供します。

## GIF 録画

フォーカス中のプレビュー上にプラグイン自身のコントロールストリップ（**録画**・**停止**・**破棄**、**フレームレート**入力（1〜50、既定 30）と状態表示）を追加します。録画中は**録画**が**一時停止**に、一時停止中は**再開**に変わります。**停止**で書き出し設定を開き、**破棄**は書き出すことなく録画を削除します。フレーム数の入力はありません。既定のショートカット：**F7** 録画／一時停止／再開、**Shift+F7** 一時停止、**F8** 停止して書き出し、**F9** 破棄。ショートカット設定で変更でき、フォーカス中の物理演算プレビューにのみ作用します。一時停止中の時間はフレームを追加しません。録画は設定パネルとコントロールストリップを除くモデルのフレームバッファを読み取ります。録画終了後、書き出しダイアログでパーセント拡大率・ピクセル幅／高さ・縦横比の固定を指定できます。**目標サイズに最適化**は既定で有効、上限は **20 MB**（1 MB = 1,000,000 バイト）。最適化により色数と解像度が低下する場合がありますが、全フレームと再生時間は保持されます。チェックを外すとサイズ上限なしで指定寸法のまま書き出します。

設定を確認してから保存先を選択します。最後に書き出しに成功した GIF 用フォルダーはセッションをまたいで記憶され、プロジェクトの保存先には影響しません。書き出しに失敗した場合も録画は保持され、設定を変えて再試行できます。キャンセル、プレビューを閉じる、プラグインを無効化すると一時録画は削除されます。

GIF の書き出しには **Gifsicle** のローカルインストールが必要です。`gifsicle` を `PATH` に追加するか、書き出しダイアログで実行ファイルのパスを指定するか、`-Dturboism.gifsicle.path=<パス>` を設定してください。プログラムの自動ダウンロードは行いません。録画中はプレビューを開いたままサイズを変更しないでください。

## 機能概要

- **ネイティブの課題解消：** 多数の物理演算グループ（髪の毛、揺れ物、リボン、服の揺れなど）を持つ Live2D モデルでは、Cubism の「物理演算・シーンブレンド設定」で個々の挙動を検証・切り分ける際に、グループのチェックボックスを1つずつ手動でオン/オフする必要がありました。また、ウィンドウを閉じると設定状態がリセットされる場合があり、繰り返し作業の負担となっていました。
- **表頭の3状態チェックボックス：** 物理演算グループリストのヘッダー（`JTableHeader`）の有効列に、ネイティブスタイルの3状態チェックボックスを組み込みます。
- **統合状態の動的表示：** すべての行の状態に応じて、全選択（チェック済み）、全解除（未チェック）、一部選択（未確定・ダッシュ表示）を動的に反映します。
- **ワンクリック一括切り替え：** ヘッダーのチェックボックスをクリックすることで、全グループの一括有効化または一括無効化を実行します（一部のみ有効または全無効時は全有効化、全有効時は全無効化）。
- **原子的ホストトランザクション：** 一括変更は検証済みの Cubism ホストトランザクション（`checkpoint` / `commit` / `rollback`）を介して安全にコミットされ、障害発生時も安全にロールバックしてモデルデータの整合性を保ちます。
- **選択行の維持：** 一括切り替え後も、現在テーブル上で選択されている行のハイライト状態が維持されます。
- **再表示時の状態保持：** 同一モデルセッション内で物理演算設定ウィンドウを閉じて再度開いた際、直前に設定した各グループの有効/無効状態が自動的に復元されます。
- **クリーンなライフサイクル：** 無効化またはホットリロード時には、リスナーを解除し、ネイティブのヘッダーレンダラーに戻し、メモリ上の状態を破棄します。孤立したフックやモデルファイルへの不要なデータ書き込みは発生しません。

## インストールと有効化

この公式プラグインは Turboism に同梱され、**プラグインマーケット**からも入手できます。インストール済みプラグインの有効化、無効化、アンインストールは**プラグイン管理**で行います。

## 使い方

1. **プラグイン管理**で「物理演算設定拡張」プラグインが有効になっていることを確認します。
2. Cubism の上部メニューから **モデリング** → **物理演算・シーンブレンド設定を開く** を選択します。
3. 左側の **物理演算グループ** リストで、有効列のヘッダーに追加されたチェックボックスを確認します。
4. ヘッダーチェックボックスをクリックしてグループを一括切り替えします：
   - 一部のみ有効（未確定状態）または全無効の場合、クリックすると全グループが有効化されます。
   - すべてのグループが有効の場合、クリックすると全グループが無効化されます。
5. 個別の行の切り替えにも対応し、ヘッダーの表示状態は自動的に更新されます。
6. ウィンドウを閉じて再度開いても、設定した各グループの有効状態が自動的に維持されます。

## プライバシーとデータ

### ネットワーク

ネットワーク接続は行いません。

### ローカルデータ

GIF 録画では一時ファイルと指定された GIF を書き込み、最後に成功した出力先フォルダーをローカル設定に保存します。グループ状態はモデルセッションのメモリ上で保持し、プロジェクトファイルは変更しません。

### テレメトリー

このプラグインはテレメトリーを送信しません。

プラグイン ID が付加されたプラグインのライフサイクル記録と障害記録が、Turboism のセッションログおよび Cubism のホストログに記録されることがあります。

## 状態と制限

- **ステータス:** プレビュー。
- アクティブな Cubism ホストでサポートされる Physics Editor 拡張サービスが必要です。
- **機能範囲の限定:** 本プラグインは独自の物理シミュレーターではなく、Cubism ネイティブの物理演算エディター全体を置き換えるものでもありません。グループリストの表頭一括選択、セッション内再表示保持、プレビューの GIF 録画を提供し、振り子の物理パラメータ（周期、反応、減衰、加速度など）や入出力設定アルゴリズムは変更しません。
- **セッション内保持:** 状態保持はメモリ上のアクティブなモデルセッション内でのみ有効であり、モデルファイル自体にカスタムメタデータを永続化することはありません。
- ウィンドウが開いている状態でプラグインを無効化した場合、ネイティブのヘッダーレンダラーが安全に復元されます。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| 表頭にチェックボックスが表示されない | 「物理演算・シーンブレンド設定」を開く前にプラグインが有効化されていることを確認してください。開いた状態で有効化した場合は、一度閉じて開き直してください。また、ホストバージョンがサポート対象であることを確認してください。 |
| クリックしても状態が切り替わらない | テーブルのセル編集状態が完了しているか確認してください。Turboism のログでトランザクションのロールバックや警告が出ていないか確認してください。 |
| 再表示時に状態が復元されない | 状態保持は同一モデルの単一セッション内でのみ保持されます。モデルを開き直した場合や、プラグインを再読み込みした場合は初期状態にリセットされます。 |
| 表頭が横線（未確定状態）になっている | 一部のグループのみが有効になっている場合、ヘッダーは未確定状態（indeterminate）を表示します。これは正常な動作であり、クリックすると全グループが有効化されます。 |
