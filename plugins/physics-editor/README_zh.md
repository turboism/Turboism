# 物理运算设置增强

> **Turboism 官方插件** · **状态：预览**

为 Cubism 原生「物理运算/场景混合设定」对话框的物理组列表新增表头全选/全不选复选框，并在同一会话内重新打开该窗口时自动保留各组的启用状态。

## 功能概述

- **解决原生痛点：** 在拥有较多物理运算组（如各层发丝、衣物飘带、身体晃动等）的 Live2D 模型中，Cubism 原生「物理运算/场景混合设定」窗口缺少批量控制操作，创作者在排查问题或预览特定效果时只能逐个手动点击勾选；同时在重新打开窗口时，临时调整的启用状态容易重置，带来重复操作负担。
- **表头三态复选框：** 在物理运算组列表表头（`JTableHeader`）的启用列直接集成原生风格的三态复选框。
- **综合状态动态呈现：** 根据当前所有行的启用情况，实时显示全部启用（勾选）、全部禁用（未勾选）或部分启用（半选/横线 indeterminate 状态）。
- **一键批量切换：** 点击表头复选框即可快速完成全部启用或全部禁用（部分启用或全部禁用时点击变为全选；全部启用时点击变为全不选）。
- **原子化宿主事务：** 批量修改通过经审核的 Cubism 宿主事务（`checkpoint` / `commit` / `rollback`）原子提交，确保所有组状态一次性生效，并在遇到异常时安全回滚，维护模型数据一致性。
- **保持行选区：** 批量切换后自动恢复当前高亮选中的行，不干扰针对单行的参数查看与调试。
- **会话内重开状态保留：** 在同一模型编辑会话期间，关闭并重新打开物理运算设定窗口时，自动恢复此前配置的物理组启用/禁用状态。
- **安全生命周期：** 插件停用或热重载时，干净地卸载鼠标监听器、还原原生表头渲染器并清理内存状态，不残留孤立钩子，不向工程写入私有脏数据。

## 安装与启用

此官方插件随 Turboism 捆绑发布，也可通过**插件市场**获取。在**插件管理**中启用、禁用或卸载已安装的插件。

## 使用方法

1. 确认已在**插件管理**中启用「物理运算设置增强」插件。
2. 通过 Cubism 顶部主菜单打开原生窗口：**建模** → **打开物理运算/场景混合设定...**（或使用对应快捷键）。
3. 在左侧面板的**物理运算组**列表中，查看启用列的表头，即可看到新增的复选框。
4. 点击表头复选框进行批量切换：
   - 当前存在部分启用（半选）或全部禁用时，点击将启用全部物理组。
   - 当前所有物理组均处于启用状态时，点击将禁用全部物理组。
5. 单独勾选或修改任意行时，表头复选框会自动联动刷新综合状态。
6. 在当前模型会话中关闭并重新打开该窗口，各组启用状态将自动保留，无需重复调整。

## 隐私与数据

### 网络

不建立网络连接。

### 本地数据

不写入插件自有文件，也不修改磁盘上的 `.cmo3` 模型文件结构。组启用状态保留严格维持在当前模型编辑会话的内存中，关闭模型或退出 Cubism 即自动释放。

### 遥测

本插件不会发送遥测数据。

带有插件 ID 的插件生命周期和故障记录可能会出现在 Turboism 的会话日志及 Cubism 的主机日志中。

## 状态与限制

- **状态：**预览。
- 需要活动 Cubism 主机中受支持的 Physics Editor 贡献服务。
- **功能范围限定：**本插件并非独立的物理模拟器，也不替代 Cubism 原生物理编辑器。插件聚焦于组列表表头全选与会话内重开状态保留，不修改摆锤物理参数（周期、反应、衰减、加速度等）及输入输出映射算法。
- **会话级保留：**状态保留仅作用于当前活动模型会话内存中，不会向模型工程持久化私有数据。
- 在窗口打开状态下停用插件会自动恢复原生表头渲染器，不会打断正在进行的操作。

## 故障排除

| 症状 | 检查事项 |
|---|---|
| 表头缺少全选复选框 | 确认在打开「物理运算/场景混合设定」前插件已处于启用状态。若在未启用时打开了窗口，请关闭后重新打开。检查宿主版本是否处于支持列表中。 |
| 点击表头无反应或未能更新 | 检查表格是否处于正在编辑单元格的状态。查看 Turboism 会话日志中是否有事务回滚或宿主服务未就绪警告。 |
| 重新打开窗口后状态未保留 | 状态保留仅在同一模型的单次会话内生效；若已关闭并重新打开了模型文件，或在重新打开窗口前停用/重载了插件，则会重置为模型原生初始状态。 |
| 表头显示为横线/半选状态 | 当部分组处于启用、部分组处于禁用时，表头显示为半选状态属于正常现象，此时点击即可一次性全部启用。 |
