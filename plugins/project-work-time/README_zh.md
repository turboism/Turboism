# 工程工作时间

在 Cubism 底部状态栏显示本次会话的累计前台用时，以及当前工程跨会话的累计工作时间。

## 功能

- **会话**：Cubism 本次启动后处于前台的总时间。
- **工程**：当前工程标签页跨会话累计的前台工作时间。
- 切换到其他应用时暂停计时，切换工程标签页时自动开始新的统计段。
- 数据由 Turboism 运行时统一采样和持久化，其他插件可通过 `ProjectWorkTimeService` 读取同一份统计。

## 使用

1. 在插件管理中启用本插件。
2. 打开至少一个工程标签页，查看 Cubism 底部状态栏的两个指标。
3. 停用插件会移除状态栏标签，累计数据仍保存在运行时状态目录中。

## 权限与数据

- `turboism.cubism.project.read`：读取运行时工程用时统计。
- `turboism.ui.status.notify`：在状态栏显示指标。
- 不联网；累计用时和工程名称保存在 Turboism 运行时状态目录。
