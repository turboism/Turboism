# 프로젝트 작업 시간

Cubism 상태 표시줄에 현재 세션의 전경 시간과 현재 프로젝트의 세션 간 누적 작업 시간을 표시합니다.

## 기능

- **세션**: 이번 Cubism 실행 이후 전경에 있던 총 시간입니다.
- **프로젝트**: 현재 프로젝트 탭의 세션 간 누적 전경 시간입니다.
- 다른 앱으로 전환하면 시간 측정을 멈추고, 프로젝트 탭을 전환하면 새 구간을 시작합니다.
- Turboism 런타임이 하나의 추적기를 운영하므로 다른 플러그인도 `ProjectWorkTimeService`에서 같은 통계를 읽을 수 있습니다.

## 사용 방법

1. 플러그인 관리에서 이 플러그인을 활성화합니다.
2. 프로젝트 탭을 열고 Cubism 하단 상태 표시줄의 두 지표를 확인합니다.
3. 플러그인을 비활성화하면 상태 표시줄 라벨은 제거되지만 누적 데이터는 런타임 상태 디렉터리에 남습니다.

## 권한 및 데이터

- `turboism.cubism.project.read`: 런타임 프로젝트 작업 시간 통계를 읽습니다.
- `turboism.ui.status.notify`: 상태 표시줄에 지표를 표시합니다.
- 네트워크에 연결하지 않습니다. 누적 시간과 프로젝트 이름은 Turboism 런타임 상태 디렉터리에 저장됩니다.
