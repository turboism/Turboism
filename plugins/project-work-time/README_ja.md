# プロジェクト作業時間

Cubism のステータスバーに、今回のセッションの前面表示時間と、現在のプロジェクトのセッションをまたぐ累計作業時間を表示します。

## 機能

- **セッション**：今回 Cubism を起動してから前面にあった合計時間。
- **プロジェクト**：現在のプロジェクトタブのセッションをまたぐ累計前面時間。
- 他のアプリに切り替えると計測を止め、プロジェクトタブを切り替えると新しい区間を開始します。
- 計測は Turboism ランタイムが一元管理し、他のプラグインは `ProjectWorkTimeService` から同じ統計を取得できます。

## 使い方

1. プラグイン管理で有効にします。
2. プロジェクトタブを開き、Cubism 下部のステータスバーに表示される 2 つの指標を確認します。
3. 無効にするとステータスバーのラベルは削除されますが、累計データはランタイムの状態ディレクトリに残ります。

## 権限とデータ

- `turboism.cubism.project.read`：ランタイムのプロジェクト作業時間統計を読み取ります。
- `turboism.ui.status.notify`：ステータスバーに指標を表示します。
- ネットワーク接続は行いません。累計時間とプロジェクト名は Turboism のランタイム状態ディレクトリに保存されます。
