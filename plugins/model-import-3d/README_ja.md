# 3D モデルのインポート

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

静的な不透明 GLB、glTF、OBJ/MTL、およびモデル ZIP パッケージをネイティブ Cubism メッシュとしてインポートします（PNG/JPEG ベースカラーテクスチャ、XYZ 全周回転、有界ジオメトリ最適化に対応）。

## 機能概要

対応する GLB、glTF、OBJ、およびモデル ZIP パッケージをネイティブ Cubism メッシュとしてインポートします。入力解析、テクスチャ正規化、ジオメトリ簡略化、パラメータ作成はすべてローカルで実行されます。元マテリアル保持モードでは、X/Y 回転を高密度なワープキーフォームに、Z 回転をネイティブのスカラーキーフォームにバインドし、各軸とも −180°〜180° の回転に対応します。最外層の「全体配置」デフォーマでモデル全体の移動・拡縮が可能で、1 回のネイティブ Undo 操作でインポート全体を取り消せます。直接頂点パスでは楕円補間と適応サンプリングを用い、簡略化と補間の合計誤差を 5px 以内に収めつつフォーム容量を削減します。

読み込み確認画面には小さな 3D プレビューが表示されます。ドラッグで回転、ホイールで拡大縮小、ボタンで視点をリセットできます。プレビュー操作は読み込むモデルを変更しません。読み込み後、パラメータツリーとプロジェクトパレットが自動更新されます。

## プリセットからインポート

モデルプロジェクトを開き、**プラグイン → 3D モデル → プリセットからインポート…** を選択します。立方体、正四面体（三角錐）、三角形、円柱、球体、正方形、円形、厚みのないリング、平たい両面のリング壁、トーラスの GLB を同梱しています（合計約 48 KiB）。XYZ 各軸 ±180° の回転と 1 回の Undo に対応します。正方形、三角形、円形、厚みのないリングは両面表示です。正四面体の 4 面は UV の 2 列 × 2 行に配置されています。平たいリング壁（半径 1、高さ 0.3）は内外の両面を表示し、同じ画像を共有します。

各プリセットは共有の 256×256 UV グリッド画像を 1 枚使用します。インポート後、画像サイズと UV 配置を維持してモデル画像を差し替え、必要に応じてテクスチャアトラスを更新してください。立方体の各面は 3 列 × 2 行、円柱の側面は V=0…0.5、上下端面は V=0.5…1 に配置されています。トーラスの主半径は 1、管半径は 0.3 です。

## 要件と互換性

- **SDK API 範囲:** `[0.67.0,1.0.0)`。
- **キャンバス要件:** インポート前に 1024×1024 キャンバスのモデルを開いてください。メニューからのインポートでは、モデルが半径 400px の境界球に収まるようカメラとピボットを自動設定します。
- **入力形式:** 単体の GLB、glTF、OBJ、または必要なリソースをまとめた ZIP（最大 16 MiB、関連リソース最大 64 個）に対応します。外部の MTL、buffer、PNG/JPEG テクスチャが参照されている場合はファイル選択ダイアログで順次指定できます。

## インストールと有効化

Turboism 公式リリースパッケージに同梱されています。インストーラーで選択するか、**プラグイン管理** から有効化・無効化できます。

## 使い方

1. 1024×1024 キャンバスのモデルドキュメントを開きます。
2. メニューから **プラグイン → 3D モデル → 3D モデルのインポート…** を選択します。
3. 元マテリアル保持モード（±180° XYZ 回転）または面カラー確認モード（XYZ 各軸 ±180°）を選択し、GLB、glTF、OBJ、またはモデル ZIP を選択します。外部リソースが必要な場合は案内に従って選択します。
4. 確認ダイアログでメッシュ数とパラメータバインディング数を確認して確定します。
5. 追加された **X / Y / Z 回転** パラメータを動かして回転を確認します。モデル全体の移動・拡縮には最外層の **全体配置** デフォーマを使用してください。

## 機能

プラグインマニフェストでは機能（ケイパビリティ）は宣言されていません。

インポーターは公開 SDK のモデル作成、ネイティブパラメータバインディング、ファイル選択認可、および単一の Undo 可能なトランザクションを使用して動作します。

## 権限

- `turboism.action.register`: 3D モデルインポートのアクションを登録します。
- `turboism.ui.menu.contribute`: 3D モデルインポートのメニュー項目を追加します。
- `turboism.ui.file-chooser.request`: 対象のモデルファイルまたは ZIP パッケージの選択をユーザーに求めます。
- `turboism.file.read`: 選択されたモデルファイルおよび関連テクスチャを読み取ります。
- `turboism.cubism.model.read`: 対象モデルとパラメータの状態を確認します。
- `turboism.cubism.model.write`: 単一の Undo 可能なトランザクションでメッシュとパラメータフォームを作成します。

## プライバシーとデータ

入力ファイルは SDK のファイル認可を通じてローカルで読み取られ、外部へのアップロードやテレメトリー送信は行いません。インポートによって元のモデルファイルが上書きされることはなく、診断情報はローカルの Turboism ログにのみ記録されます。

## 状態と制限

- **ステータス:** プレビュー。
- ベースカラーは単色または不透明な 8-bit RGB/RGBA PNG/JPEG（デコード後の RGBA 合計 4 MiB 以内、CLAMP_TO_EDGE および LINEAR サンプリング）に対応します。透過、リピート／ミラーラップ、ミップマップ、カラープロファイルを含む画像はオブジェクト作成前に拒否されます。
- 不透明な閉じた凸形状、凸四角形平面、および有界簡略化対象のサーフェスに対応します。任意の凹トポロジーや自己交差・循環遮蔽を持つサーフェスは拒否されます。
- 対象ドキュメントの切り替えやプラグインの無効化が行われた場合、進行中のインポートは安全に中止されます。

## トラブルシューティング

- **メニューが表示されない:** プラグイン管理でプラグインが有効になっているか確認してください。
- **インポートが拒否される:** キャンバスサイズが 1024×1024 であるか、ファイルサイズが 16 MiB 以下であるか、対応する形状・マテリアル制限を満たしているか確認してください。
- **ドキュメント切り替え後に停止した:** 対象モデルを開き直してから再度インポートを実行してください。
