# パラメーターバッチ転送

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

選択した 1 つの ArtMesh またはデフォーマから、複数の対象パラメーターへパラメーターのバインディングを転送します。

| 詳細 | 値 |
|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.parameter-batch-transfer` |
| カテゴリー | `modeling` |
| タグ | parameter, batch-edit, transfer |
| Turboism API | `[0.1.0,0.2.0)` |
| Cubism が必要 | はい |
| インターフェース | `swing` |
| ライセンス | プロジェクトライセンス |

## 機能概要

- デフォーマ、パーツ、ワークスペースオブジェクトのコンテキストメニューにバッチ転送項目を追加します。
- 選択した 1 つの ArtMesh、Warp Deformer、または Rotation Deformer から、モーダルな対象選択セッションを構築します。
- 確認済みの転送を、任意の反転とともに適用し、各結果を報告します。

## 要件と互換性

- **Turboism API:** `[0.1.0,0.2.0)`。
- **Cubism:** Cubism が必要です。Turboism は現在、レビュー済みの正確な Editor アーティファクト `5.2.03`、`5.3.02`、`5.3.03` を受け入れます。本プラグインは、宣言されたサービスと機能が利用できる場合にのみ、各ホスト向け機能を公開します。
- **インターフェースモード:** `swing`。
- **プラグイン依存関係:** 宣言されていません。

## インストールと有効化

この公式プラグインは、まだ公開ストアに掲載されていない**ストア候補**です。マーケットプレイスで公開されるまでの間は、Turboism の公式リリースパッケージを通じてインストールし、**Plugin Management** で有効化してください。このワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールできます。

## 使い方

1. 既にパラメーターバインディングを持つ、対応する ArtMesh またはデフォーマをちょうど 1 つ選択します。
2. そのコンテキストメニューを開き、バッチ転送コマンドを選択します。
3. 転送先パラメーターを選択し、必要に応じて反転を選び、ダイアログを確定して転送を適用します。

## 機能

| 宣言された機能 | ユーザーへの効果 |
|---|---|
| `cubism.parameter.read` | ソースバインディングと利用可能な対象パラメーターを読み取ります。 |
| `cubism.parameter.write` | 確認済みのバインディング変更を書き込みます。 |
| `cubism.parameter.bindings.transfer` | 任意の反転とともに、型付きバインディング転送を実行します。 |
| `ui.context-menu.contribute` | 対応するコンテキストにバッチ転送ランチャーを追加します。 |
| `ui.status.notify` | 前提条件と転送結果を報告します。 |

## 権限

| 権限 | スコープ | 要求する理由 |
|---|---|---|
| `turboism.cubism.model.read` | `application` | 転送セッション用に、選択されたオブジェクトのパラメーターバインディングとモデルのパラメーター一覧を読み取ります。 |
| `turboism.cubism.model.write` | `application` | 型付き Editor オーサリング API を通じて、確認済みのパラメーターバインディング転送を適用します。 |
| `turboism.action.register` | `application` | コンテキストメニュー項目の背後にあるバッチ転送の開始アクションを登録します。 |
| `turboism.ui.context-menu.contribute` | `application` | デフォーマタブ、パーツタブ、ワークスペースオブジェクトのコンテキストメニューにバッチ転送項目を公開します。 |
| `turboism.ui.status.notify` | `application` | 転送結果と前提条件によるスキップを通知します。 |

## プライバシーとデータ

### ネットワーク

ネットワーク接続を行いません。

### ローカルデータ

プラグインデータを永続化しません。選択されたオブジェクトのバインディング状態を読み取り、確認済みの対象バインディングを書き込みます。

### テレメトリー

このプラグインからテレメトリーが送信されることはありません。

プラグイン ID を付して、プラグインのライフサイクルおよび障害の記録が Turboism のセッションログと Cubism のホストログに表示される場合があります。

## 状態と制限

- **ステータス:** プレビュー。
- 対応するソースオブジェクトがちょうど 1 つと、既存のソースバインディングが少なくとも 1 つ必要です。
- 確認済みの対象行は個別に転送されます。本プラグインは、1 つに統合された取り消しグループを提供するとは主張しません。
- モーダルな Swing ダイアログはヘッドレス JVM では利用できません。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| コンテキストコマンドがない | デフォーマ、パーツ、またはワークスペースオブジェクトのコンテキストで、対応するオブジェクトを 1 つ選択します。 |
| ダイアログにソースバインディングがない | 既存のパラメーターバインディングがあるオブジェクトを選択します。 |
| 転送がスキップされる | 転送先の有効性、選択状態、状態通知にある拒否された行を確認します。 |
