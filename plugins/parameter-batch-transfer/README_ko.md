## 기능 개요

- デフォーマ、パーツ、キャンバスのコンテキストメニューにバッチ転送項目を追加します。
- 選択した 1 つの ArtMesh、Warp Deformer、または Rotation Deformer から、モーダルな対象選択セッションを構築します。
- 確認済みの転送を、任意の反転とともに適用し、各結果を報告します。

## 설치 및 활성화

この公式プラグインは、まだ公開ストアに掲載されていない**ストア候補**です。マーケットプレイスで公開されるまでの間は、Turboism の公式リリースパッケージを通じてインストールし、**Plugin Management** で有効化してください。このワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールできます。

## 사용 방법

1. 既にパラメーターバインディングを持つ、対応する ArtMesh またはデフォーマをちょうど 1 つ選択します。
2. そのコンテキストメニューを開き、バッチ転送コマンドを選択します。
3. 転送先パラメーターを選択し、必要に応じて反転を選び、ダイアログを確定して転送を適用します。

## 기능

| 宣言された機能 | ユーザーへの効果 |
|---|---|
| `cubism.parameter.read` | ソースバインディングと利用可能な対象パラメーターを読み取ります。 |
| `cubism.parameter.write` | 確認済みのバインディング変更を書き込みます。 |
| `cubism.parameter.bindings.transfer` | 任意の反転とともに、型付きバインディング転送を実行します。 |
| `ui.context-menu.contribute` | 対応するコンテキストにバッチ転送ランチャーを追加します。 |
| `ui.status.notify` | 前提条件と転送結果を報告します。 |

## 개인정보 및 데이터

### 네트워크

ネットワーク接続を行いません。

### 로컬 데이터

プラグインデータを永続化しません。選択されたオブジェクトのバインディング状態を読み取り、確認済みの対象バインディングを書き込みます。

### 원격 측정ー

このプラグインからテレメトリーが送信されることはありません。

プラグイン ID を付して、プラグインのライフサイクルおよび障害の記録が Turboism のセッションログと Cubism のホストログに表示される場合があります。

## 상태 및 제한 사항

- **ステータス:** プレビュー。
- 対応するソースオブジェクトがちょうど 1 つと、既存のソースバインディングが少なくとも 1 つ必要です。
- 確認済みの対象行は個別に転送されます。本プラグインは、1 つに統合された取り消しグループを提供するとは主張しません。
- モーダルな Swing ダイアログはヘッドレス JVM では利用できません。

## 문제 해결

| 증상 | 확인 사항 |
|---|---|
| コンテキストコマンドがない | デフォーマ、パーツ、またはキャンバスのコンテキストで、対応するオブジェクトを 1 つ選択します。 |
| ダイアログにソースバインディングがない | 既存のパラメーターバインディングがあるオブジェクトを選択します。 |
| 転送がスキップされる | 転送先の有効性、選択状態、状態通知にある拒否された行を確認します。 |
