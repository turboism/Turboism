# パラメーター同期プラグイン

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

Live2D Cubism Editor でチェックしたパラメーター同士を正規化範囲割合に基づいてリアルタイム同期します。

| 詳細 | 値 |
|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.parameter-sync` |
| カテゴリー | `modeling` |
| タグ | parameter, sync, link, workflow |
| Cubism が必要 | はい |
| インターフェース | `swing` |
| ライセンス | プロジェクトライセンス |

## 機能概要

- スライダーのドラッグ、数値入力、または外部駆動時に、操作されたパラメーターの正規化進捗割合を他のすべての選択済みパラメーターへ即座に同期します。
- 単一の統一ダイアログ：上部に全体有効化スイッチと同期パラメーター数、中央の表に各パラメーターの独立したチェックボックスを配置しています。
- Turboism イベントシステムとプログラム書き込み抑制機能により、反発発振やパフォーマンス低下を完全に防止します。
- モデル固有の GUID によるセッション間永続化に対応しています。

## 要件と互換性

- **SDK API 範囲:** `[0.67.0,1.0.0)`。

## インストールと有効化

この公式プラグインは Turboism に同梱されており、**Plugin Market** からも入手できます。**Plugin Management** から有効化、無効化、またはアンインストールが可能です。

## 使い方

1. パラメーターパレット内の任意のパラメーターを右クリックします。
2. **パラメータ同期...** を選択して設定ダイアログを開きます。
3. 連動させたいパラメーターをチェックし、**保存して閉じる** をクリックします。
4. パレットやキャンバスでチェックしたパラメーターをドラッグすると、他のパラメーターも滑らかに同期します。

## 機能

| 宣言された機能 | ユーザーへの効果 |
|---|---|
| `cubism.parameter.read` | アクティブなモデルからパラメーター値、範囲、名称を読み取ります。 |
| `cubism.parameter.write` | 対象パラメーターに同期値を書き込みます。 |
| `cubism.model.observe` | モデルの開閉ライフサイクルイベントを検知して同期ルールを復元します。 |
| `event.subscribe` | リアルタイムのパラメーター値変更イベントを購読します。 |
| `ui.context-menu.contribute` | パラメーターパレットのコンテキストメニューに同期操作を追加します。 |
| `ui.status.notify` | 同期状態の変更や切り替え通知を行います。 |
| `file.read` | プラグインストレージから保存済みの同期ルールを読み取ります。 |
| `file.write` | プラグインストレージに同期ルールを永続化保存します。 |

## プライバシーとデータ

### ネットワーク

ネットワーク接続を行いません。

### ローカルデータ

モデル GUID に紐づくプラグインサンドボックスストレージに設定を保存します。モデル GUID とパラメーター ID 文字列のみを含みます。

### テレメトリー

このプラグインからテレメトリーが送信されることはありません。

プラグイン ID を付して、プラグインのライフサイクルおよび障害の記録が Turboism のセッションログと Cubism のホストログに表示される場合があります。

## 状態と制限

- **ステータス:** プレビュー。
- 正規化割合マッピングを用いて、アクティブモデル内のチェックされたパラメーターを同期します。
- アクティブなモデルドキュメントが必要です。
- 選択されたパラメーターが2個未満の場合は同期されません。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| パラメーターが同期しない | パラメーター同期が有効化されており、2つ以上のパラメーターがチェックされていることを確認してください。 |
| コンテキストメニュー項目がない | エディタ上でモデルが開かれていることを確認してください。 |
| 同期が一時停止している | 右クリックメニューの「パラメータ同期を切り替え」またはダイアログ上部のチェックボックスで有効化してください。 |
