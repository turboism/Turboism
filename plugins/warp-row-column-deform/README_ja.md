# ワープ行・列変形

| 項目 | 値 |
|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.warp-row-column-deform` |

ワープデフォーマの行全体または列全体の制御点を一括移動できるカスタム一時変形ツールを追加します。**モデリング -> 一時変形ツール** と **ツール詳細** ドロップダウンから起動できます。

Turboism 0.70.3-beta.4 以降にはこのプラグインが同梱されます。対応する環境にない場合は、プラグインマーケットからインストールできます。それ以前のビルドでは一時変形ツール SDK を利用するためにアップデートが必要です。
