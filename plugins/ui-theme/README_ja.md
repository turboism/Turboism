# UI テーマプラグイン

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

組み込みおよびユーザーのテーマパッケージを管理し、レビュー済みのセマンティックな外観変更を Cubism に適用します。

| 項目 | 値 |
|---|---|
| バージョン | `0.1.0` |
| プラグイン ID | `dev.turboism.plugin.uitheme` |
| カテゴリー | `appearance` |
| タグ | theme, colors, user-interface |
| Turboism API | `[0.1.0,0.2.0)` |
| Cubism が必要 | いいえ |
| インターフェース | `none` |
| ライセンス | プロジェクトライセンス |

## 機能概要

- テーマの状態、マネージャー、組み込みテーマの適用、インポート、エクスポート、編集、削除、ネイティブテーマの復元のワークフローを追加します。
- サイズが制限された ZIP テーマパッケージを検証し、ユーザーパッケージをプラグインデータにアトミックに保存します。
- セマンティックな外観の適用に成功した後にのみ選択したテーマを保存し、無効化時には所有する外観を復元します。

## 要件と互換性

- **Turboism API:** `[0.1.0,0.2.0)`。
- **Cubism:** このプラグインは Cubism なしでも初期化できます。Cubism にテーマを適用するには、正確にレビュー済みの Editor アーティファクト（`5.2.03` または `5.3.02`）とセマンティック外観サービスが引き続き必要です。
- **インターフェースモード:** `none`。
- **プラグイン依存関係:** 宣言されていません。

## インストールと有効化

この公式プラグインは**ストア候補**であり、まだ公開済みのストア掲載ではありません。マーケットプレイスで公開されるまで、Turboism の公式リリースパッケージからインストールし、**Plugin Management** で有効にしてください。このワークフローが不要な場合は、同じウィンドウから無効化またはアンインストールしてください。

## 使い方

1. **Turboism → Theme Manager** または提供されるワークスペースのコンテキストメニューコマンドを開きます。
2. 組み込みテーマを選択するか、ユーザーテーマを作成または編集するか、検証済みのテーマ ZIP をインポートします。
3. 選択内容を適用します。Cubism 本来の外観を復元するにはネイティブテーマオプションを使用します。必要に応じて、マネージャーからユーザーパッケージをエクスポートまたは削除できます。

## プライバシーとデータ

### ネットワーク

ネットワーク接続は行いません。

### ローカルデータ

選択したテーマを `ui-theme/selection.cfg` にあるプラグイン設定に保存します。ユーザーパッケージは、`themes/<theme-id>.zip` としてプラグインデータ下に保存されるサイズ制限付き ZIP アーカイブです。インポート/エクスポートでは、ユーザーが承認した不透明なファイルハンドルを使用します。バンドルされたテーマはプラグインの `themes/` リソースから読み取られます。

### テレメトリー

このプラグインはテレメトリーを送信しません。

プラグイン ID が付加されたプラグインのライフサイクル記録と障害記録が、Turboism のセッションログおよび Cubism のホストログに記録されることがあります。

## 状態と制限

- **ステータス:** プレビュー。
- テーマアーカイブ、ID、エントリー数、エントリーサイズ、および合計サイズには上限が設けられ、検証されます。無効なパッケージは利用できません。
- Cubism の外観を適用するには、レビュー済みのセマンティック外観サービスが必要です。マネージャーは Cubism なしでも存在できますが、サポートされない場合、ホストの外観変更はフェイルクローズドで失敗します。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| テーマを適用できない | 現在のホストがレビュー済みの外観サービスを公開しているか確認し、状態通知を確認してください。 |
| インポートしたパッケージが拒否される | 有効なテーマ ID とサポート対象のエントリーを備えた、サイズ制限内で有効な Turboism テーマ ZIP であることを確認してください。 |
| 再起動後にテーマがない | `ui-theme/selection.cfg` を確認し、選択したユーザーパッケージがプラグインデータにまだ存在することを確認してください。 |
