# 外部PSD編集プラグイン

> **Turboism 公式プラグイン** · **ステータス: プレビュー**

ArtMesh を右クリックして完全な原画 PSD を OS 既定の PSD アプリケーションで編集し、保存するたびに Cubism ネイティブの明示ターゲット原画置換を適用します。

## 機能概要

- ArtMesh 対応コンテキストメニュー（パーツ、デフォーマ、ワークスペースオブジェクトビュー）に「外部編集 (PSD)」項目を追加します。
- 型付きテクスチャ関係グラフを通じて選択された各 ArtMesh を現在の原画（Raw Image）に解決し、異なる原画ごとに 1 つの編集セッションを開きます。重複選択や既に開いている原画は自動的に重複排除されます。
- ArtMesh が現在テクスチャアトラスから描画されている場合、保持されているモデル画像入力がすべて同一の原画に解決されるときのみ追跡します。欠落・不明・曖昧なソースは拒否し、描画入力を切り替えることはありません。
- Cubism ネイティブのレイヤー画像書き出しによって完全な原画 PSD をランタイム管理下の一時ファイルへ書き出し、OS 既定の PSD アプリケーションを起動します。
- 一時ファイルを監視し、安定した保存が行われるたびに Cubism ネイティブの明示ターゲット原画置換を適用します。
- セッション中は読み取り専用の関係リフレッシュを行い、Undo/Redo による原画変更を追跡します。
- セッション・インポート・一時停止の状態を非ブロッキング通知で報告し、不確実なネイティブ結果が発生した場合は推測せずセッションを一時停止します。

## 要件と互換性

- **SDK API 範囲:** `[0.67.0,1.0.0)`。
- **Cubism:** 必須。書き出しと置換には Cubism ネイティブのレイヤー画像書き出しおよび原画置換機能（Cubism 5.2.00 以降）を使用します。
- **インターフェースモード:** `embedded`。
- **プラグイン依存関係:** なし。
- 一時 PSD は再構築されたドキュメントであり、元アセットのバイトコピーではありません。

## インストールと有効化

Turboism 公式リリースパッケージに同梱されています。インストーラーで選択するか、**プラグイン管理** から有効化・無効化できます。

## 使い方

1. モデルドキュメントを開き、1 つ以上の ArtMesh を選択します。
2. 右クリックして外部 PSD 編集メニュー項目を選択します。
3. 複数の新しい原画に解決される場合は確認ダイアログで承認します。
4. 外部アプリケーションで編集して保存すると、保存のたびに元の原画へ自動反映されます。
5. プラグインを無効化するかドキュメントを閉じるとセッションが終了します。一時ファイルや外部アプリケーションは閉じられずにそのまま残ります。

## 機能

マニフェストでは ArtMesh から PSD への編集パイプライン用に `cubism.psd.external-edit`、メニュー項目用に `ui.context-menu.contribute`、セッション通知用に `ui.status.notify`、複数ファイル確認ダイアログ用に `ui.dialog.contribute` を宣言しています。

## 権限

- `turboism.cubism.model.read` — テクスチャ関係を読み取り、ArtMesh を原画へ解決してセッションバインディングを検証します。
- `turboism.cubism.model.write` — 保存時にネイティブの明示ターゲット原画置換を適用します。
- `turboism.cubism.model.observe` — モデルクローズおよびエディター終了のライフサイクルコールバックを受け取り、外部編集セッションを停止します。
- `turboism.file.read` — 置換のためにランタイムが発行した一時 PSD のリビジョンを読み取ります。
- `turboism.file.write` — 完全な原画 PSD をランタイム管理下の一時ファイルへ書き出します。
- `turboism.process.run` — OS 既定の PSD アプリケーションで一時 PSD を開きます。
- `turboism.ui.status.notify` — セッション、インポート、一時停止／失敗の通知を表示します。
- `turboism.ui.dialog.contribute` — 複数の一時 PSD を開く前に一度確認ダイアログを表示します。
- `turboism.action.register` — コンテキストメニューから呼び出されるアクションを登録します。
- `turboism.ui.context-menu.contribute` — ArtMesh 対応コンテキストメニューに項目を追加します。
- `turboism.ui.context-source.read` — 編集開始時にキャプチャされたコンテキストメニュー選択を読み取ります。

## プライバシーとデータ

### ネットワーク

ネットワーク接続は行いません。

### ローカルデータ

システムの一時領域下にランタイム管理の一時 PSD ファイルを書き込み、置換のために読み戻します。セッション終了後も一時ファイルは削除せず、外部アプリケーションも終了させません。セッション間でプラグインデータは保存されません。

### テレメトリー

テレメトリーは送信しません。

プラグインのライフサイクルやエラー記録は、プラグイン ID 付きで Turboism セッションログに記録される場合があります。

## 状態と制限

- **ステータス:** プレビュー。
- 書き出される PSD は Cubism ネイティブのレイヤー画像再構築によるものです。Cubism がモデル化しない PSD 固有の構造は往復保持が保証されません。
- 発行された一時ファイルへの上書き保存のみがインポート対象です。別名保存やコピーの編集では置換は発生しません。
- 複数のモデル画像や ArtMesh で共有されている原画は 1 回だけ編集され、置換はすべての依存オブジェクトに反映されます。
- 不確実なネイティブ結果により一時停止したセッションを再開するには、プラグインを一度無効化してから再度有効化し、新しくセッションを開始してください。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| メニュー項目を選択しても何も起きない | 選択対象に ArtMesh が含まれているか、キャプチャされたドキュメントが現在のアクティブモデルと一致しているか確認してください。 |
| 警告後に自動置換が止まった | 不確実なネイティブ結果のためセッションが一時停止しています。プラグインを無効化・再有効化してから再度実行してください。 |
| 保存しても反映されない | 外部アプリケーションが同じ一時ファイルに上書き保存しているか確認してください。 |
| 2 回目の右クリックで「既に開いています」と表示される | その原画には既にアクティブなセッションがあります。既存の外部エディターウィンドウを使用してください。 |
| 確認後に何も開かない | 権限の取り消しや原画の利用不可により安全に中止された可能性があります。 |
