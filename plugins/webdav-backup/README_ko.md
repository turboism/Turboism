## 기능 개요

- WebDAV バックアップ設定とエンドポイントテスト用の Turboism メニュー項目を追加します。
- 保存トリガーまたはホストの自動バックアップによって生成された `.cmo3` 成果物を、制限付きの再試行でアップロードできます。
- JDK `HttpClient` を使用します。資格情報は、表示される設定および診断情報から除外されます。

## 요구 사항 및 호환성

- **インターフェースモード:** `swing`。

## 설치 및 활성화

この公式プラグインは Turboism に同梱され、**プラグインマーケット**からも入手できます。インストール済みプラグインの有効化、無効化、アンインストールは**プラグイン管理**で行います。

## 사용 방법

1. **Turboism → WebDAV バックアップ設定** を開きます。
2. HTTP(S) エンドポイント、リモートパス、任意のユーザー名とパスワード、トリガーモード、タイムアウト、TLS、再試行設定を入力し、保存前にエンドポイントをテストします。
3. 同期を有効にします。設定されたトリガーが発生すると、該当するバックアップ成果物がアップロードされます。

## 개인정보 및 데이터

### 네트워크

ユーザーが設定した WebDAV HTTP(S) エンドポイントに接続し、`MKCOL`、`PROPFIND`、`PUT` を使用します。任意の Basic 認証では、設定されたユーザー名とパスワードがそのエンドポイントに送信されます。転送は、設定された保存または自動バックアップトリガーの後に自動的に実行される場合があります。TLS 検証を無効にするとクライアントは任意の証明書を受け入れるため、ネットワーク攻撃者がバックアップ通信を傍受できます（MITM）。信頼できるプライベートエンドポイント以外では有効のままにしてください。

### 로컬 데이터

エンドポイント設定と資格情報を `backup/webdav.cfg` のプラグイン設定に保存します。パスワードは平文で保存されます——設定ストアに資格情報ボールトはなく、所有者限定のファイル権限が保護境界です。パスワード値はダイアログではマスクされ、ログおよびオブジェクトレンダリングからは編集除去されます。プラグインはアップロードするために、対象となるバックアップファイルを読み取ります。

### 원격 측정ー

このプラグインからテレメトリが送信されることはありません。

プラグイン ID が付与されたプラグインのライフサイクル記録および障害記録が、Turboism のセッションログと Cubism のホストログに表示される場合があります。

## 상태 및 제한 사항

- **ステータス:** プレビュー。
- 到達可能な WebDAV サーバーと Cubism の保存/バックアップライフサイクルイベントが必要です。
- 無効なファイル、エンドポイントの失敗、中断されたリクエスト、および再試行の上限到達はフェイルクローズで処理されます。サーバーがアップロードを受け入れるまで、リモートバックアップの成功は仮定されません。

## 문제 해결

| 증상 | 확인 사항 |
|---|---|
| エンドポイントテストに失敗する | URL、リモートパス、資格情報、TLS 設定、およびサーバーの WebDAV サポートを確認してください。 |
| バックアップがアップロードされない | 同期が有効であること、トリガーモードがイベントに一致することを確認し、プラグインスコープのログ記録を調べてください。 |
| サーバーエラーが繰り返される | HTTP ステータスと再試行設定を確認してください。プラグインが再試行するのは、上限のある一時的な失敗のみです。 |
| アップグレード後に WebDAV 項目が 2 つ表示される | プラグインは `plugins/webdav-backup.jar` に改名されました。管理アップグレードは改名前の `backup.jar` を埋め込みプラグイン id で削除し、旧 id `dev.turboism.plugin.backup` はランタイムが拒否します。ロックされたファイルをインストーラーが削除できなかった場合のみ、残った `backup.jar` を手動で削除してください。 |
