## 기능 개요

独立した現在ページ用のテクスチャ配置プラグインです。材質ローカルの凹形輪郭、保守的なビットマスク、スキップ探索を使い、開いた凹部や別領域の間に小部品を配置します。正確な矩形のみの入力は軽量 BSSF 経路を使用し、不定形は輪郭衝突検査を維持します。他の配置プラグインへの依存はありません。

## 요구 사항 및 호환성

Java 17+、Turboism API [0.67.4,1.0.0)、自動生成一覧にある Cubism 5.0–5.3 が必要です。5.2–5.3 は輪郭配置に対応し、5.0–5.1 では輪郭サービスが利用できない場合に矩形配置を使用します。既存の AUTO バックエンド値と bitmask-nesting 診断を使用し、SDK 列挙型の追加は不要です。

## 설치 및 활성화

`./gradlew :plugins:atlas-bitmask-nesting:jar` でビルドし、Turboism のプラグイン管理から JAR をインストールして有効化します。開発モジュールのため正式配布には含まれません。

## 사용 방법

現在のテクスチャページを開き、ネイティブ自動配置の一覧で **Bitmask Nesting** を選択します。倍率、余白、回転を設定して実行します。回転無効時は現在の角度を保持し、有効時は90度刻みと最小外接矩形の方向を候補にします。余白3pxは輪郭間で最低6pxを確保します。固定倍率は縮小せず、自動倍率は100%以下です。

## 기능

`cubism.texture-atlas.layout` でアルゴリズムを登録します。スナップショット、検証、変換の書き戻し、取り消し、古い対象の拒否はランタイムが担当します。

## 권한

`turboism.cubism.model.read` は輪郭と現在の変換を読み取ります。`turboism.cubism.model.write` は検証済み配置をランタイム経由で適用します。

## 개인정보 및 데이터

形状はメモリ内で処理します。元画像の出力、モデルファイルの保存、通信、テレメトリ送信は行いません。ログには部品数、倍率、グリッド幅、計算時間が記録されます。

## 상태 및 제한 사항

開発版です。ネイティブ入口では現在ページを処理します。フォルダー別配置を含む全アトラス SDK 要求は利用可能なメッシュ輪郭（未取得時は画像全体の矩形）を原寸・回転なしで配置し、ページ上限内で分割するか型付き配置エラーを返します。輪郭未取得時は SDK の矩形フォールバックを使用します。閉じた穴は SDK により保守的に埋められます。既定グリッドは各辺最大512セル（4096ページで8px）、DENSE SDK要求は1024セルです。余白は別途確保します。画像のアルファから輪郭を再構築しないため、円形画像でもメッシュが矩形なら矩形として扱います。有限の位置と角度で速度と密度を調整します。決定的な直列ヒューリスティックで、最適密度や最大倍率は保証しません。並列オプションは無効です。

## 문제 해결

一覧に表示されない場合は有効状態、宿主バージョン、ログを確認してください。固定倍率で入らない部品は現在ページのオーバーフロー契約に従います。`./gradlew :plugins:atlas-bitmask-nesting:test` で幾何回帰、`:plugins:atlas-bitmask-nesting:nestingBenchmark` で合成入力の計算時間を測定できます。宿主 UI 全体の時間とは異なります。
