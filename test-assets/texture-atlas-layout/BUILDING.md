# 纹理图集测试模型构建与复现说明 (BUILDING.md)

本文档记录 `texture-atlas-layout` 测试集（Circle 与 Geometry 系列，共 9 个 CMO3 + 8 个 PSD）的已知规格事实、生成逻辑及复现说明。

---

## 1. 设计目标与背景

该测试集专门用于评估 Live2D Cubism Editor 纹理图集当前页排版（Texture Atlas Auto-Layout）算法的效率、空间利用率和稳定性：
- **Circle 系列**：同尺寸圆形几何。用于建立统一尺寸、规则边界下的算法性能基线（消除不同形状尺寸对排版复杂度的干扰）。
- **Geometry 系列**：异尺寸、异形状、异长宽比几何。用于检验实际复杂工程中多变尺寸、旋转适配与碎片空间利用率。
- **500x2 变体**：双页/高密度配置，用于检验多纹理页排版与边界行为。

所有二进制资产遵循 **CC0 1.0** 开放许可，通过 `scripts/test_corpus.py fetch texture-atlas-layout` 获取。

---

## 2. 已知事实与技术规格

### 2.1 文件头与格式特征

- **CMO3 模型**：文件头部魔数为 `CAFF`（Live2D Cubism 模型工程格式）。
- **PSD 文件**：文件头部魔数为 `8BPS`，版本为 1（标准 Photoshop 格式），颜色模式为 RGB，位深度为 8-bit，4 通道。

### 2.2 Circle 系列规格

| 模型/PSD | PSD 画布尺寸 | 颜色通道 | PSD 图层记录数 | CMO3 文件大小 |
|---|---|---|---:|---:|
| `circle_100` | 4096×4096 | 8-bit RGB (4通道) | 100 | 850,522 字节 |
| `circle_500` | 4096×4096 | 8-bit RGB (4通道) | 500 | 3,538,094 字节 |
| `circle_1000` | 4096×4096 | 8-bit RGB (4通道) | 1,000 | 7,731,906 字节 |
| `circle_2500` | 4096×4096 | 8-bit RGB (4通道) | 2,500 | 18,691,242 字节 |

- **图形特征**：每个图层包含一个大小完全相同的实心圆形图案。
- **输入数与纹理页说明**：PSD 图层数不等同于 Cubism Editor 原生某次当前页排版实际接收的输入数。在实机环境下，网格生成状态与图集当前页选择会影响实际排版调用输入（宿主实测数据参见 `validation/texture-atlas-current-page/HOST-AB.md`）。

### 2.3 Geometry 系列规格

| 模型/PSD | PSD 画布尺寸 | 颜色通道 | PSD 图层记录数 | CMO3 文件大小 |
|---|---|---|---:|---:|
| `geometry_100` | 2048×2048 | 8-bit RGB (4通道) | 100 | 694,856 字节 |
| `geometry_500` | 2048×2048 | 8-bit RGB (4通道) | 500 | 3,564,178 字节 |
| `geometry_1000` | 2048×2048 | 8-bit RGB (4通道) | 1,000 | 6,701,324 字节 |
| `geometry_2500` | 2048×2048 | 8-bit RGB (4通道) | 2,500 | 24,581,494 字节 |
| `geometry_500x2` | *(基于 500)* | - | - | 6,978,687 字节 |

- **图形特征**：图层内容为大小各异、形状各异、长宽比不一的几何形状。
- **`geometry_500x2` 变体**：单工程包含双张纹理页或双倍排版模型图像设置，用于跨纹理页及极端负载对照验证。

## 4. 附录：生成同类结构 PSD 的参考说明

若在没有原始环境的情况下需要程序化生成类似结构（多图层、独立透明形状）的测试 PSD，可以使用标准 PSD 结构写入工具。

> **重要提示**：自行生成的 PSD 文件在压缩格式、元数据、图层记录字节流及随机分布上必然与原版存在差异，其 SHA-256 哈希值**无法匹配**官方基准。基准测试与自动化门禁必须通过 `scripts/test_corpus.py fetch` 使用官方 CC0 归档。

### 确定性结构生成骨架概念（仅供参考）：

```python
# 概念示例：使用标准图形库生成多图层同类图像
# 注意：此骨架仅用于展示同类测试 PSD 的生成思路
def create_circle_test_spec(count: int, canvas_size: int = 4096):
    """
    已知规格：
    - 画布: canvas_size x canvas_size, RGBA, 8-bit
    - 图层数: count (100 / 500 / 1000 / 2500)
    - 图层内容: 每个图层一个等径圆形，分布于画布不同坐标
    """
    return {
        "canvas_width": canvas_size,
        "canvas_height": canvas_size,
        "layer_count": count,
        "shape_type": "uniform_circle",
    }
```
