# 局部刷新最小设计

这是后续实现规范，**当前未启用局部刷新**。目前最小切口位于 Normal 的切片派发层，保留原生 common 和逐轴顺序，避免重写插值数学。

1. 在受控源编辑入口携带明确原因、对象身份、结构代际和普通源 GUID/版本；类型、scale、普通/扩展键 raw bits、绑定顺序、网格/属性形状、Normal/Morph 状态均须完整检查。仅凭鼠标拖动或 EditVersion 变化不足以证明其他输入未变。
2. 任何局部写入前完成准入检查。未知 force 原因、Undo/Redo、结构/类型/scale/绑定/键变化、Morph 存在、别名/身份异常、未知类或不完整签名全部走原生。需要重建时由原生重建，旧图立即失效。
3. 图记录 source→slice 和输出→后续 slice，严格按原生轴与片顺序求脏闭包。不能并行改写跨轴依赖。全部源改变或闭包成本接近全量时继续原生。
4. 每个被跳过片须先建立原生“实际写入目标、顺序、属性、point setter 次数及 EditVersion 增量”的效果记录。目标列表包含锚点，不能把列表成员数或顶点数当成实际调用次数。**该效果记录与补偿目前未证明，是启用阻断项**；不能直接调用一次 setUpdated 冒充等价。
5. 设计图若跨调用存活，须有显式结构代际失效、条目/内存预算与生命周期清理，避免强引用延长模型寿命。尚未决定宿主绑定或弱引用方案，不引入常驻全局模型图。
6. 下一步最小验证顺序：在目标版只观测原生切片和 setter 效果 → 同模型源编辑回放签名/闭包 → 比较坐标、全部属性、绝对版本与调用顺序 → 类型/scale/键/拓扑/历史失效 → SNS 与 Morph 专项 → 各依赖族逐版本验证 → 再做真实交互 A/B。每一步未知即全量。

当前三个 ELLIPSE 隔离用例只支持几何/部分 Rotation 属性候选算法，版本增量已经出现差异；不得将其直接安装进本轮已通过的生产包。也不据此删除 Part 广播或把 force=true 改成 false。
