## 提交审阅的资源界限

以下是基于已测范围提出的边界，**尚未批准**，不虚构既有产品预算：

| 指标 | 实测最坏值 | 提议边界 |
| --- | ---: | ---: |
| 三命令 Java 总 CPU 回归 | 无回归，最低减少 16.40% | 不回归（≤0%） |
| 操作绝对 RSS 峰值相对 off 增长 | +17.84% | ≤20% |
| on 操作峰值高于自身基线 | 68.133 MiB | ≤80 MiB |
| on 三轮驻留第三减第一 | +42.855 MiB | ≤64 MiB |

内存边界是略高于观测最大值的圆整审阅范围；三周期不能估计长期漂移或
证明稳定平台。这些边界仅适用于本候选、三精确版本、指定 heavy fixture
与三个实际命令周期，不扩大版本/模型准入，不修改 Atlas 原验收标准。
如这些内存代价不可接受，当前生产 gate 必须保持未通过。

人工审阅来源：权威 spec 的 SC-04a 明确规定“CPU与内存具体回归上限待实测
基线后提出供用户审阅，不自行虚构已批准阈值”；Turboism Spec Kit 第4节
规定“Lane C 的 exact-host 证据由人工 review”。仅实机运行授权不等于资源
阈值审批，也不包含合并许可。
