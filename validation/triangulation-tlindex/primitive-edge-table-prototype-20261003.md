# T071 owned primitive edge-table prototype

An independent long-key metadata table passed **3,776,818 checks** against `HashMap<Long,Object>`. This is a diagnostic prototype; runtime production code remains T057. No full-index integration, premain admission, allocation-byte estimate or native performance result is claimed.

The table stores primitive long keys and bucket references in parallel arrays, with a power-of-two capacity and at most two-thirds occupancy. Empty slots are represented by null references, so zero and every other long value remain valid keys. Values must be nonnull, matching the intended private index bucket contract. Lookup uses the current full-bit edge mix and exact long equality. Deletion shifts only entries whose linear probe path crosses the gap, including wrapped clusters; the final free key/value slot is cleared. Growth reinserts existing exact references. `clear()` releases all values while retaining backing capacity. This changes metadata representation only; existing edge bucket lists, triangle objects and native algorithms are outside the prototype.

The deterministic selfcheck covers zero, negative/sentinel and extreme keys; forced wrapped collision clusters with deletion at every position; 300,000 random insert/overwrite/remove/query operations; repeated growth and clear; returned previous-reference identity; cardinality; occupied/free-slot integrity and removed-value retention. Values throw on `equals/hashCode`, proving the table does not invoke them. Null insertion is rejected without altering the table. Java 17 lint/Werror and full JVM verification PASS.

Reproduce with `javac --release 17 -Xlint:all -Werror` on `diagnostic/PrimitiveEdgeTableSelfCheck.java`, then `java -Xverify:all` on the resulting class. Raw classes and result log are retained in `build/t071-primitive-edge-table-r1/`; the accompanying JSON pins inputs and outputs.

This harness does not establish production exceptional behavior, actual triangle index order or snapshot independence.
