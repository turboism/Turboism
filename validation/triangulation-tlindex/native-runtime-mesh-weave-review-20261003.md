# T084: actual runtime native mesh suffix weave and helper

The runtime patcher and helper are implemented and pass three-version native
controls. They are not connected to the production transformer or an extended
SDK dependency plan. Delivery remains frozen T057; no Editor, host comparison,
new accepted candidate or performance gain is claimed.

`NativeMeshEdgePatcher` accepts only the two exact official mesh class hashes.
It wraps only the final autoConnect suffix after native generation/progress,
leaves the earlier native return unchanged, and closes the scope on normal and
Throwable exits. It substitutes only the typed search's original unfiltered
lookup with a slot/ABSENT/UNKNOWN branch. UNKNOWN calls the original invokespecial
search; ABSENT preserves null. Native addEdge version update, normalization,
constructor, append and typed promotion remain original. Successful native
append gets one registration hook. Double weave and unknown class bytes refuse.
It uses existing ASM core visitors; no new runtime dependency was added.

`NativeMeshEdgeLookup` public entry first requests the extended shared gate.
Missing admission refuses before metadata/table creation. ClassValue access
requires exact field/endpoint signatures and loader identities. Owned scopes
consume their definition lease on success and refusal, initialize actual bounded
primitive storage from literal first physical slots, and restore prior thread
state on close. Normal/refused/exceptional disposal releases buffers and lease.
Unexpected list size/identity, edge identity, capacity or access failure discards
the table and returns UNKNOWN. Filtered lookup and other receivers use native
search. Null/empty/truncated/degenerate triangle arrays decline; the degenerate
logger path remains native. Reflected fatal getter failures are unwrapped and
propagate after disposal. Table capacity derives from existing edges plus the
maximum insertion count, bounded by 16,384 keys and the existing 4MiB ledger.

and JVM verification are exercised. Complete owned controls replace only entry

Three same-size mutation counterexamples are explicitly retained for each version
and assertion mode: direct set, subList.set and listIterator.set. Each replaces
