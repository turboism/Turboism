## Mutation and callback admission

contract; it does not make the published mesh private or promise safe concurrent

introduced. EDT placement alone is not the admission proof.

The captured mesh is final. Every starting edge and the list must have exact

nonnull checks operate on the already-validated array and NORMAL enum constant.
The remaining trusted JDK operations have no application element equality,
comparison or listener callback. This trust base is the standard JDK and the sole
trusted Agent protocol, not a security boundary against hostile reflection/JNI,
escaped raw instrumentation or arbitrary JDK tampering.

Under that exact call closure, same-thread external set, subList/listIterator
mutation, progress callback reentry and UI event pumping cannot occur inside the
