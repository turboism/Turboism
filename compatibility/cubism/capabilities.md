## Version monotonicity

Within one minor line, a newer patch is a superset of an older patch: capabilities and commands admitted on `5.x.y` stay admitted on `5.x.y'` for `y' > y`. Cross-line differences (for example `5.2.03` versus `5.3.00`) are genuine host boundaries, not regressions.

## Querying availability at runtime

Plugins should not branch on the version string; query the capability instead. Every `CubismFacade` accessor returns a sentinel whose `isAvailable()` reports admission, `EditorCommand#supports(String)` / `supportedVersions()` expose per-command sets, and annotated surfaces fail closed with `CubismEditorApiUnavailableException` when the host does not admit them.
