# Cubism Editor 互換性 — ファーストパーティプラグイン

> `scripts/generate_compatibility_matrix.py` により生成。バージョンカバレッジ変更後は再生成してください（`--check` は `devCheck` で強制されます）。

すべての行はリポジトリ内のレビュー済み互換性データから生成されています。**対応バージョン**はプラグインの宣言ケイパビリティが解決される正確なレビュー済み Editor 成果物を示し、**バージョン差分**には一部バージョンでのみ利用可能な機能を記載しています。

## FREE / PRO ライセンスについて

Cubism を FREE ライセンスで実行すると、保存は FREE のパラメータ数などの制限を受けます。PRO（PRO トライアルを含む）ではこの制限はありません。Turboism プラグインのバージョン対応はライセンス階層とは無関係です。制限はランタイムが許可する API ではなく、エディタが保存できる内容に適用されます。
