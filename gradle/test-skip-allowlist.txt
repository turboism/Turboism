# Sanctioned test skips.
#
# Every Test task is checked after execution by
# buildSrc/src/main/java/dev/turboism/gradle/internal/TestExecutionGuard.java.
# A skipped test fails the build unless it is registered here, so a suite can no
# longer pass by skipping everything.
#
# Format: one entry per line, `<fully-qualified-test-id-glob> # <reason>`.
# The id is `<classname>.<method>` exactly as Gradle writes it to the JUnit XML
# result; `*` matches any characters. The trailing reason is mandatory. Lines
# starting with `#` and blank lines are ignored.
#
# Removing a skip from a test must remove its entry here in the same change;
# stale entries are harmless but mask the next real skip, so keep this list short.
