Turboism managed fx runtime distribution notice

Turboism distributes fx version 0.0.5 runtime assets for use by the
Turboism with fx plugin.

Upstream source commit:
df7e6245e1992758d4060c97477ceafa27770551

The Linux and macOS payloads are unmodified official Vercel upstream release
assets. The Windows x86-64 executable is a Turboism product build of that
upstream source, not an official Vercel Windows asset. It is distributed only
inside Turboism Full products and is verified by exact size and SHA-256 before
launch:

size: 11174912 bytes
SHA-256: 04eca2ccb0037d4080724ad644cb42a2605f610632e0e95148f077e1550c4541

The current Windows candidate intentionally provides a narrower feature set.
It does not claim durable-session, ACP MCP-server, native-tool, networking,
process, or persistence parity with the official Linux and macOS assets.
Windows repair is performed by repairing or reinstalling Turboism Full; there
is no upstream Windows archive for online repair.
