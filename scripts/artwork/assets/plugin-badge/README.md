# Turboism 第一方标记素材

此处的 T 角标**仅用于 Turboism 框架和第一方插件**，用于区分 Cubism 原生功能与 Turboism 第一方功能。第三方插件不使用此标记，接入 SDK 或上架商店不赋予第一方身份。

- `turboism-plugin-badge.svg`：正常状态的矢量素材。
- `turboism-plugin-badge-disabled.svg`：禁用状态的矢量素材。
- `*-7.png` 等 PNG：文件名数字表示角标本身的像素尺寸，不含放置边距。

素材由共享定义生成，请勿单独修改输出文件。完整尺寸、配色、状态与合成规范见[图标规范](../../README.md)。
