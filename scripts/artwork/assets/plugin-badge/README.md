# Turboism First-Party Badge Assets

The T badge here belongs to **the Turboism framework and the first-party plugins only**, and it separates a native Cubism feature from a first-party Turboism feature. A third-party plugin never uses the mark, and adopting the SDK or listing in the store grants no first-party identity.

- `turboism-plugin-badge.svg`: the vector asset of the normal state.
- `turboism-plugin-badge-disabled.svg`: the vector asset of the disabled state.
- A PNG such as `*-7.png`: the trailing number is the pixel size of the badge itself and excludes the placement margin.

A shared definition generates the assets, so never edit an output file alone. The complete size, color, state, and composition rules are in the [icon guide](../../README.md).
