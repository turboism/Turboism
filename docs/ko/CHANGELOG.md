## [0.70.3] - 2026-11-23

이전 정식 버전 **0.70.2** 이후 변경 사항입니다.

### 추가

- SDK에서 플러그인이 사용자 지정 임시 변형 도구를 등록할 수 있습니다.
- 워프 디포머의 제어점을 행 또는 열 단위로 움직이는 워프 행/열 변형 플러그인을 기본 패키지에 포함했습니다. 호환 설치에 이 플러그인이 없으면 플러그인 마켓에서 설치할 수 있습니다.
- 캔버스 핸들로 대칭 축을 옮길 수 있습니다. ArtMesh Mirror에 축 잠금과 초기화를 추가하고 피벗을 속이 빈 원으로 표시합니다.
- 업데이트 후 선택한 언어로 릴리스 노트를 표시합니다.
- ACP가 agy CLI를 인식합니다.
- 설정 -> 성능에 '워프 디포머 및 브러시 편집 가속', '대화형 메시 편집 가속', '텍스처 아틀라스 캔버스 상호작용 가속', 'Cubism 메모리 및 OpenGL 리소스 누수 완화' 네 가지 항목을 추가했습니다. Windows 설치 프로그램 설정 병합이 이 네 필드를 받아들이고, 최적화 프리셋이 모두 활성화합니다.

### 변경

- 무할당 인덱스 파츠 순회, 모프 타깃 키 캐시, O(1) 미변경 메시 에폭 건너뛰기, Cubism 5.3+ 원시 타입 베지어 가속, 컴파일된 정렬 접근자, 셰이더 머티리얼 파라미터 쌍 캐시를 통해 모델링 드래그, 베지어 워프 평가, 파츠 순회, 파라미터 패널 다시 그리기 성능을 더욱 높였습니다.
- 설정 -> 성능을 5개의 명확한 섹션으로 통합하여 기본 활성 최적화를 11개의 3상태 체크박스로 묶고, 기본 비활성 또는 충돌 항목 11개를 접힌 '레거시 및 실험적 옵션' 섹션으로 옮겼으며, 6개 언어 툴팁을 알기 쉬운 표현으로 개편했습니다. 0.70.3 beta.3에서 업그레이드할 때(기본값 버전 v1 -> v2) 명시적 해제 설정과 OFF 프리셋은 그대로 유지하면서 프레임 끝 지연 GL 오류 검사를 자동으로 활성화합니다.
- 무할당 렌더 행렬·재질 패스, 모프 버퍼 재사용, 비활성 선택 오버레이 생략, 원시 타입 베지어 그리드·키폼 조회 고속 경로, 무잠금 메시 준비 추적, ConstantDynamic 최적화 슬롯 디스패치로 렌더링, 디포머 편집, 대화형 메시 편집 속도를 더욱 높였습니다.
- 드래그 입력 지연을 줄였습니다. OpenGL 드라이버 작업을 미루고 독립적인 변형 작업을 병렬로 실행합니다. 중복 팔레트 갱신을 건너뜁니다.
- 캔버스 컨텍스트 메뉴에서 플러그인 동작을 그룹화합니다.
- 복잡한 디포머를 드래그할 때는 영향을 받는 하위 트리만 갱신합니다. 대기 중인 드래그 이벤트를 합치고 인스펙터 재구성을 미룹니다.
- 성능 그룹 전체를 체크박스로 제어할 수 있습니다. 균형 프리셋은 검증된 기본값을 따릅니다. 워프 위치 투영은 기본적으로 꺼집니다.
- 시작 설정에 업데이트 채널과 시작 옵션을 명확히 표시하고 대화 상자 동작을 간소화했습니다.
- 편집 모드의 워프 변형, 변형 브러시, 베지어 그리드 평가, 오버레이 업로드가 빨라졌습니다. 재초기화 버퍼 재사용, 역이차 및 베지어 고속 경로, 오버레이 변경 감지, 부동 소수점 루프 통합을 사용합니다.
- 대화형 메시 편집이 빨라졌습니다. 삼각형 내부 판정 가속, 오버레이 스프라이트 캐시, 뷰포트 클리핑, 드래그 UI 갱신 통합, 비 Delaunay 자동 연결에서 변경되지 않은 배열 건너뛰기를 사용합니다.
- 텍스처 아틀라스의 확대, 이동, 타일 드래그에서 프레임마다 발생하던 벡터 재래스터화와 중복 드래그 UI 동기화를 제거했습니다.
- 프레임워크 업데이트가 실제 네트워크 다운로드 진행률과 검증된 바이트를 따로 보고하며, 스테이징되었거나 적용 대기 중인 업데이트는 불확정 진행 막대 대신 완료된 진행률을 표시합니다.
- 프레임워크 업데이트가 대상 매니페스트에서 이름이 바뀐 변경되지 않은 파일을 재사용하므로, 경로만 이동하는 버전 업그레이드에서 같은 바이트를 다시 받지 않습니다.
- 프레임워크 JAR 조립이 검증된 로컬 아카이브에서 변경되지 않은 ZIP 항목 구간을 재사용하고, 변경된 항목만 HTTP 범위 요청으로 내려받습니다. 아카이브 형식, 범위 규약, 절감 기준을 충족하지 않으면 전체 다운로드로 돌아갑니다.
- 이전에 직접 켜야 했던 여러 최적화가 플랫폼 기본값으로 켜집니다. 메시 보간, 셰이더 uniform 조회, 행렬 스크래치 재사용, 모델 인스턴스 통합, 확장 보간 동일 출처 생략, 워프 그리드 보간, 워프 법선 점 생략, 카메라 행렬 캐시, 렌더 패스 순회, 메시 히트 테스트, 씬 핸들러 캐시, 커서 검증 생략, 워프 디포머 편집 가속, 매개변수 행 다시 그리기입니다. `config.json`의 명시적인 사용자 선택이 여전히 우선하며, 모든 스위치는 설정 -> 성능에서 끌 수 있습니다.
- 워프 위치 투영의 허용 조건이 '정확히 Java 17'에서 'Java 17 이상'으로 완화되었습니다.
- 커서 검증 생략이 JDK 25의 `MouseInfo.getPointerInfo` 호출 형태를 인식하므로 `SecurityManager` 제거 후에도 정확하게 동작합니다.
- 네이티브 셰이더 uniform 조회가 리플렉션 호출 대신 메서드 핸들을 사용합니다. 거부된 조회는 공식 질의로 대체되며 원래 예외를 유지합니다.

### 수정

- 캔버스 재초기화 및 패널 폐기 시 공유 OpenGL 컨텍스트 전반의 대기 중인 VBO를 GL 오류 없이 정리하고, ArtMesh 미러가 메시별로 축 잠금·각도·피벗을 저장하며 핸들을 중앙에 표시하고, 3D 모델 프리셋 가져오기 시 장면을 대체하기 전에 확인을 요청하며, 기하학 메시 배치에서 동심 링을 중심 살과 독립적으로 연결하도록 수정했습니다.
- 메시 배치 중 형상과 도구 모음 선택을 유지합니다. 자동 메시는 선택한 프리셋을 유지합니다. Turbo Mesh의 투명 여백, 영역 분리 및 적응형 정점 배치를 개선했습니다.
- ACP의 Antigravity 검색과 DeepSeek 모델 선택을 개선했습니다.
- Cubism 5.3에서 자동 메시를 생성할 때 올바른 ArtMesh 업데이트 브리지를 사용합니다.
- ACP가 Markdown 표를 렌더링하고 코드 블록 대비를 개선합니다. 대화 기록 오류를 표시하고 컨텍스트 힌트를 한 번만 표시합니다.
- Cubism의 파츠 패널이 문서를 닫은 뒤 다시 초기화되며 네이티브 로그와 코어 로그가 동기화됩니다.
- 업데이트 창의 채널 컨트롤을 왼쪽으로 정렬합니다.
- 검증된 메모리 및 OpenGL 완화가 폐기된 VBO와 텍스처를 해제하고, 실행 취소 기록을 제한하며, 닫힌 문서와 검사기 참조를 정리하므로 장시간 편집에서도 무한히 증가하지 않습니다.
- 파트 팔레트가 키 리스너를 하나만 유지하고 중복 트리 재구성을 건너뛰므로, 모델을 열어 둔 채 문서를 전환해도 리스너가 쌓이지 않습니다.
- 빌드가 직전 메인 브랜치 커밋이 서식 없이 남긴 훅 소스에 고정된 Palantir Java Format 스타일을 적용하므로 릴리스 서식 게이트가 다시 통과합니다.

## [0.70.2] - 2026-11-22

이전 정식 버전 **0.70.1** 이후 변경 사항입니다. 그동안의 Beta 변경 사항을 포함합니다.

### 추가

- 호환성을 검토한 Cubism Editor 5.3.05를 런타임 호환성 검증과 최적화 훅 전반에서 지원합니다.
- 설정 -> 성능에 기본 활성화된 '모델 열기 및 텍스처 로딩 가속'과 '런타임 파일 내보내기 가속' 옵션을 추가하고 프리셋 및 Windows 설치 프로그램 설정 병합에 연동했습니다.
- ArtMesh 표시 정보를 내보낼 수 있습니다. 텍스처 아틀라스에서 모델 이미지별로 배율을 고정할 수 있습니다.

### 변경

- 직접 OpenGL 텍스처 업로드, RGBA PNG 직접 디코딩, 무검증 JDOM XML 파싱, 제로 카피 아카이브 읽기, 비분할 실수 배열 역직렬화, 초기 확장 보간 병렬 설정으로 모델 열기와 텍스처 로딩을 가속했습니다.
- 메모리 내 JDOM·실수 배열 직접 복제, 다중 페이지 및 페이지 내 병렬 아틀라스 재구성, 스트라이프 경계 색 확장, 병렬 무손실 PNG 인코딩, 선형 시간 MOC3 인덱싱으로 런타임 내보내기를 가속하고 대형 모델의 메모리 부족 오류를 방지합니다.
- 텍스처 아틀라스에 로딩 진행률을 표시하고 기본적으로 메시를 병렬로 삼각 분할하며, 공간 인덱스로 대형 모델 로딩을 가속합니다. 로딩 최적화는 끌 수 있습니다.
- MCP와 ACP의 도구 스키마 효율, stdio 브리지 전송 지연, 병렬 하네스 탐색, 세션 정리를 개선했습니다. MCP 연결 창의 프롬프트 표기를 '에이전트용 프롬프트'로 변경하고, 프롬프트 영역에 전체 내용을 3줄로 표시합니다.

### 수정

- 아틀라스 캐시 재사용이 내용 일치 시 dirty 상태를 해제하고 캐시를 기록하여 내보내기 중 반복 전체 해싱을 방지합니다.
- ACP가 Windows 종료 시 하위 프로세스 트리를 완전히 정리하고 Pi 브리지 시간 제한 및 취소 처리를 맞췄습니다.
- 모델을 저장할 때 이미지 배율 잠금을 저장하고 문서를 닫을 때 저장하지 않은 잠금 변경을 버립니다.
- 호환성을 검토한 호스트에서 작업 공간 제어를 복구합니다. 선택적 어댑터를 사용할 수 없어도 지원되는 기능은 계속 작동합니다.
- 워프 디포머의 대칭 편집이 기본 제어점 드래그를 따릅니다. 최근 프로젝트 보드는 레이아웃을 바꿀 때 행 높이를 유지합니다.
- 업데이트 도구가 선택한 채널을 유지합니다. Windows 실행기가 Unicode 경로와 Cubism BAT 백업 충돌을 처리합니다.
- Windows 설치 프로그램이 최종 구성 중 UAC 프롬프트를 표시하고, 재설치 시 이전 프레임워크 업데이트 상태를 지웁니다.
- 서명 없는 설치 프로그램은 설치 영수증 갱신을 건너뜁니다. 제거 프로그램은 설치 경로 아래에 구성 유지 옵션을 표시합니다.

## [0.70.1] - 2026-11-18

이전 정식 버전 **0.67.4** 이후 변경 사항입니다. 그동안의 Beta 변경 사항을 포함합니다.

### 추가

- 서명된 프레임워크 업데이트가 변경 파일을 내려받고 서명을 검증합니다. 다음 관리 실행에서 적용하며 시작 복구를 지원합니다.
- 업데이트 창에서 프레임워크와 플러그인 업데이트, 번역된 설명, 진행 상황, 호환 플러그인 선택을 함께 제공합니다.
- Windows 설치 프로그램에 플러그인 개별 선택과 다국어 미리보기를 추가했습니다. 마켓에 설치 개수와 필터를 추가했습니다.
- 최근 프로젝트 보드에 캐시 미리보기, 레이아웃 전환, 이미지 삭제, 기본 모델 및 애니메이션 생성 명령을 추가했습니다.
- 프로젝트 작업 시간이 전경 편집 시간을 기록합니다. 시작 로딩 창과 제품 안내를 추가했습니다.
- 물리 설정에서 GIF와 애니메이션 PNG를 녹화합니다. 파라미터 동기화, 기하 메시 배치, 디포머 일괄 이름 변경을 추가했습니다.
- 파라미터 일괄 전송에서 바인딩을 제자리에서 반전합니다. 3D 가져오기에 파일 선택과 실시간 미리보기를 통합했습니다.
- ACP에 대화형 질문, 작업 진행, 속도 표시, 도구 접기, 영구 연결, 세션 승인, DeepSeek Harness 지원을 추가했습니다.

- 업데이트 창에서 업데이트할 프레임워크와 플러그인을 한 목록에 표시하고, 업데이트가 필요 없는 항목은 숨깁니다. 오른쪽에는 선택한 항목의 업데이트 기록을 표시합니다. 플러그인만 업데이트할 수 있으며 전체 다운로드 크기를 MB와 경과 시간으로 표시합니다. 하단 버튼은 "업데이트 확인", "업데이트 취소", "업데이트 설치" 세 개입니다. 설치를 누르면 다운로드, 검증, 준비가 자동으로 진행되며 파일 교체와 적용은 다음 실행 시 이루어집니다. 사용 가능한 프레임워크 업데이트는 항상 선택되며 한 번의 확인으로 프레임워크와 플러그인을 함께 확인합니다. 상단에는 현재 버전과 대상 버전을 양쪽에, 화살표를 가운데에 표시하고 업데이트 기록의 여백과 상태 메시지의 줄 간격을 줄였습니다. 진행률 표시줄 가운데에는 MB를, 오른쪽 끝에는 `12m31s` 형식의 경과 시간을 표시합니다. 플러그인 다운로드는 합의된 API/CDN 경로를 먼저 시도하고 사용할 수 없으면 서명된 카탈로그의 원래 GitHub Release URL로 자동 전환하며, 두 경로 모두 전체 파일 검증을 유지합니다.

- 공식 Windows Stable/Beta 패키지에 서명을 검증하는 프레임워크 자체 업데이트를 추가했습니다. Cubism 안에서 변경된 파일을 다운로드하고 선택한 호환 플러그인의 업데이트도 예약할 수 있습니다. 프레임워크 업데이트는 다음 관리 실행기 시작 시 적용되며 시작 실패 시 복구를 지원합니다. 기존 설치는 먼저 서명된 설치 영수증이 포함된 전체 패키지로 업그레이드해야 합니다.
- SDK에 플러그인 비활성화 시 UI 정리를 제한 시간 내에 수행하는 실험적 `UiScheduler.runUiTeardown(Runnable, Duration)`을 추가했습니다. EDT에서는 즉시 실행하고, 그 외에는 제한 시간까지 기다립니다. EDT가 응답하지 않거나 호출 스레드가 인터럽트되면 `false`를 반환하며, 정리 작업은 대기열에 남아 정확히 한 번 실행되고 인터럽트 플래그는 복원됩니다. 플러그인 세대 펜스는 비활성화 이후에도 이 호출을 허용합니다.
- Windows 설치 프로그램에 공식 플러그인 선택 페이지를 추가했습니다. RichEdit20W를 통해 영어, 중국어 간체, 일본어, 한국어 README를 실시간으로 렌더링하여 미리 볼 수 있으며, 전체 선택/해제, 플러그인별 설치 건너뛰기 마커 및 페이로드 필터링을 지원합니다.
- 파라미터 동기화(`parameter-sync`, 정규화 진행률 기반 실시간 연동)와 디포머 이름 일괄 변경(`deformer-batch-rename`, Cubism 네이티브 곡면/회전 아이콘 미리보기 포함)을 공식 릴리스 플러그인으로 승격하고 설치 패키지 번들 배포에 포함했습니다.
- 모든 공식 플러그인에 한국어 문서(`README_ko.md`)를 추가하고, 런타임 아카이브 메타데이터 및 패키징 지원을 완료했습니다.
- 플러그인 마켓 창에 설치됨/전체 마켓 수량 통계, 왼쪽 정렬된 상세 패널 헤더, 전체/설치됨/미설치 빠른 필터 토글을 추가했습니다.
- 부트스트랩 초기 단계에 컴팩트한 무테 로딩 창을 추가하여 에디터 인터페이스가 열리기 전 원활한 시각적 피드백을 제공합니다.
- 파라미터 일괄 반전 전송에서 임시 파라미터 생성 없이 대상 파라미터 자체에서 직접 키폼 반전 바인딩을 수행할 수 있도록 지원합니다.
- 선택 브러시 및 메시 편집 대칭 버튼에 네이티브 다크 테마 전용 툴바 아이콘과 팔레트를 적용했습니다.
- 공식 플러그인 `geometric-mesh-layout`(미리 보기)를 추가했습니다. 메시 편집 도구 모음의 도구로, 캔버스에 중심 앵커를 두고 원형 또는 정다각형 정점과 변을 생성하며 동심원 링과 방사형 스포크를 지원합니다.
- SDK에 형식화된 테이블 선택 대화상자(`SelectionTableDialogRequest`, `SelectionTableDialogRequest.Row`, `SelectionTableDialogResultListener`), `ArtMeshMirrorService.Unavailable` 및 `OrdinaryKeyformWriteSupport.Check.ABSENT` 센티널 값을 추가하고, 나머지 공개 훅, 메시, 모델, 파일 선택, PSD 인터페이스에 `@CubismEditor` 버전 주석을 추가했습니다.

### 변경

- `clipmask-viewer`와 `project-inspector`는 새 정리 API로 창을 닫으므로 최소 API가 `0.68.1`로 변경되었습니다. 다른 공식 플러그인의 하한은 그대로입니다. EDT가 제때 응답하지 않으면 `project-inspector`는 비활성화를 실패시키지 않고 경고를 기록합니다.
- 런타임은 수동으로 관리하던 목록 대신 내장된 `packaging/release-plugins.txt`에서 공식 플러그인 목록을 읽으며, 매니페스트가 없거나 잘못되면 실패합니다.
- 플러그인 마켓 배포 목록(`packaging/market-plugins.txt`)과 설치 프로그램 번들 목록(`packaging/release-plugins.txt`)을 분리하여, `parameter-lock`과 같은 공식 플러그인을 설치 프로그램 패키지 용량 증가 없이 플러그인 디렉터리에 독립적으로 게시할 수 있도록 했습니다.

- 비동기 파일 로그 작성을 바운딩하고 세션 로그 순환을 도입하여 과도한 로그 출력으로 인한 메모리 팽창을 방지했습니다.
- 성능 설정의 레이아웃, 이름, 도구 설명을 통일했습니다.
- 검토된 호스트 지원 범위를 넓혔습니다. 보호 내보내기 훅은 Cubism 5.1.00 이상을, 컨트롤 외관 및 디포머 소스 프로필은 5.0.00부터 모든 검토된 릴리스를 지원합니다.
- `acp`는 `[0.1.0,1.0.0)` 범위의 `mcp` 플러그인 버전을 허용합니다.

### 수정

- 권한 또는 의존성 설명이 긴 유효한 서명 카탈로그를 플러그인 동시 업데이트가 거부하던 문제를 수정했습니다. 클라이언트 제한을 디렉터리 v2의 유니코드 코드 포인트 2,000개로 통일했습니다.

- 새 공식 플러그인(`atlas-bitmask-nesting`, `atlas-dalsoo-polygon`, `atlas-folder-layout`, `deformer-batch-rename`, `frame-animation-import`, `parameter-sync`)만 포함한 전체 설치가 업데이터에서 thin 빌드로 잘못 판별되지 않습니다.
- WebDAV 백업 중지 테스트는 폴링 대신 작업자 스레드 종료를 기다리며, 승인 변경 테스트는 변경 훅이 실행되었는지 보고합니다.
- Cubism에서 스레드 간 네이티브 증분 콜백 재생 문제를 수정하고, 최적화 호환성을 확장했으며, 재구축된 지오메트리 및 대칭 드래그 선택 소유권을 안정적으로 무효화하도록 했습니다.
- 최근 파일 미리보기 플러그인(`recent-preview`)의 캔버스 뷰포트 캡처 및 호버 썸네일 미리보기를 복원했습니다.
- Windows 설치 프로그램의 안정성을 개선했습니다. UAC 취소를 정상적으로 처리하고, 권한 승격 대기 제한 시간을 설정하며, 손상된 BAT 실행기 설정을 자체 복구하고, 재설치 시 불필요한 GraalVM 경로를 정리합니다.
- 3D 모델 가져오기 플러그인의 업그레이드 경로를 수정하고 가져오기 확인 대화상자를 컴팩트하게 정리했습니다.
- 파라미터 동기화의 캐시 수명 주기와 프로그램 쓰기 억제 메커니즘을 강화하고 테스트 슬라이더를 제거했습니다. 디포머 이름 일괄 변경의 한국어 문장 부호를 수정하고 만료된 미리보기 감지를 개선했습니다.
- 뷰 컨텍스트 메뉴와 해당 부트스트랩 호스트 프로필이 Cubism 5.0.00–5.3.04에서 동작합니다.
- Windows 설치 프로그램의 플러그인 선택 페이지가 선택을 동기화할 때 체크박스 상태를 올바르게 읽습니다.
- `parameter-lock` 행 레이블을 클릭하면 행의 다른 위치를 클릭한 것과 동일하게 동작합니다.
- 플러그인 세대 펜스와 치명적 오류 전파를 강화했습니다.
- 검토되지 않은 호스트의 호환성 탐색이 매번 고정된 순서로 슬라이스를 순회합니다. 이전에는 실행할 때마다 순서가 바뀔 수 있었습니다.

- 입력 다이제스트를 계산할 수 없는 경우 텍스처 아틀라스 캐시가 재생성 경로로 올바르게 폴백.
- `Motion3Validator`에서 세그먼트 식별자 축소 전 수치 범위를 검사하여 오버플로 방지.
- 중단된 설치로 남은 고아 활성화 마커를 관리형 Graal 설치 프로그램이 올바르게 조정.
- 문서 전환 시 새로 바인딩된 모델을 즉시 게시하여 이전 모델 참조 고정을 방지.

  런타임 진단과 상관되고 적용된 스키마는 바인딩 런타임과 일치합니다.
- PSD Clip Mask Import가 네임스페이스 간 모델 id를 비교하여 다른 장면의 동일한 id에서
  오작동할 수 있는 문제를 수정했습니다. id 비교는 이제 하나의 네임스페이스 내에 머물고
  가져오기는 재진입 없이 진행 상황을 보고합니다.
- 페이로드 SHA-256 작업 후 Windows 설치 프로그램 완료 페이지가 비어 표시되는 문제를
  수정하고, 설치 프로그램 시작 프로그램 진단이 동시 레이블된 stdout/stderr를 안정적으로
  배출하도록 유지했습니다.
- Windows 제거 프로그램 구성 유지 확인란이 외부 마법사 창에 연결되어 안정적인 상호
  작용을 방해하고 확인 페이지를 느리게 만들 수 있는 문제를 수정했습니다.
- 제거 옵션을 명확하고 기본 활성화된 "Keep config.json" 동작으로 변경했습니다.
  구성은 사용자가 지울 때만 삭제됩니다.
- 정확한 버전 SDK 허용을 유지하면서 Cubism Editor 5.2.03에서 History 스냅샷 가용성을
  복원했습니다.
- Java가 사용 가능한 ACL 뷰 또는 기존 사용자별 Windows 경로 및 재분석 검사를 노출할 때
  Windows MCP 시작을 복원하고, 베어러 값, 엔드포인트 또는 개인 연결 파일 경로를 기록하지
  않습니다.
- 동시 레이블된 stdout 및 stderr 배출을 포함한 영구적인 구성기 및 관리형 GraalVM 하위
  프로세스 진단을 추가하여 실패한 BAT 통합 및 선택적 런타임 설정을 실행 가능하게
  만들었습니다.
- 플러그인 활성화가 빈 플러그인별 config, data, cache 디렉터리를 생성하지 못하도록
  했습니다. 저장소는 이제 첫 번째 실제 작업에 필요한 디렉터리만 생성하고, 플러그인
  로그는 공유 런타임 로그를 사용하며, 사용되지 않는 `palette-filter-attach.tsv` 진단은
  더 이상 생성되지 않습니다.
- 지원되지 않는 리플렉션 캔버스 외부 다시 그리기 시도를 제거했습니다. 테마 변경은 이제
  Cubism Editor 5.2.03 및 5.3.02에서 확인된 신뢰할 수 있는 다시 시작 필요 동작을
  사용합니다.
- fx Settings 창이 fx 셸을 열기 전에 설정된 연결이 필요하여 새 설치에서 공급자 및 모델
  설정에 도달할 수 없었던 문제를 수정했습니다.
- 사용자 지정 엔드포인트 어댑터가 fx가 모든 요청에서 보내는 reasoning 필드를 거부하고,
  `ai-language-model-id` 요청 헤더를 무시하고, 인증되지 않은 자체 호스팅 엔드포인트에
  API 키를 요구하는 문제를 수정했습니다.
- 사용자 지정 프로필이 플러그인 소유 Gateway 전용 fx 홈과 선택적 직접 `--model` 인수로
  적응된 연결을 시작하여 사용자의 일반 fx 홈에서 관련 없는 Codex 또는 Grok 선택을
  상속하는 문제를 수정했습니다.
- Turboism이 사용 가능한 공급자나 모델이 선택되지 않았다고 보고하기 전에 프롬프트
  텍스트가 지워지는 문제를 수정했습니다.
- ACP MCP 서버를 거부한 제한된 Windows fx 페이로드를 Turboism의 정확한 인증된 숫자
  루프백 HTTP MCP 서버로 제한된 독립적으로 재현 가능한 빌드로 교체했습니다.
- 관리형 Windows 시작이 경로를 포함하는 Turboism JVM 옵션을 독립 실행형 `cmd.exe`
  명령으로 재분석하는 문제를 수정했습니다. 옵션은 이제 임시 Cubism BAT에 인용된 인수로
  삽입되고 상속된 Java 옵션 변수와 오래된 Turboism 통합 블록은 하위 프로세스에서
  제외됩니다.

  호버 축소판을 안정화했습니다.
- 패키지 검사, 구성 병합, 경로 처리, 보고서 편집, 공급망 검증을 강화했습니다.

### 알려진 제한 사항

- Windows는 기본 Cubism 호스트 플랫폼입니다.
- Java 설치 프로그램은 macOS 및 Linux에서 사용할 수 있지만 macOS Cubism 호스트 준비는
  주장되지 않으며 Linux Cubism 호스팅은 지원되지 않습니다.
- 이 릴리스의 게시된 바이너리는 코드 서명되거나 공증되지 않습니다. 설치 전에 함께
  제공되는 SHA-256 사이드카를 확인하세요.
